## 1. 约定（The Pact）——碎片叙事的主容器

Pibo 在**首启**掏出一张半是古语、半是乱码、字迹残缺的**约定**，按着要你「签」
（= HealthKit 授权 + 起名）。全约 **12 条**，大多以 `█████` 涂黑/风化。
**随你照顾自己，条文乱序逐条显影**——这就是主线的骨架，非线性。

### 1.1 全 12 条（含显影门控）

| # | 显影后的文字 | 何时显影 |
|---|---|---|
| 一 | 甲方须善待己身。 | **首启即清晰**（唯一 Day-1 可读） |
| 二 | 乙方不解释自己；莫问其来处——它也不记得。 | L1 |
| 三 | 乙方以甲方身上「还活着的那部分」为食。花开则乙安，花萎则乙饥。 | L1 |
| 四 | 甲方睡得沉，乙方便能多梦见一点 █████。 | **睡眠能量**累积（L1–2） |
| 五 | 甲方走得远，乙方便多想起一段路。走得越远，想起越多。 | **运动能量**累积（L1–2） |
| 六 | 甲方以眼睛去看真的东西，乙方便认得一种花。 | **认知能量/拍照**累积（L2） |
| 八 | 甲方唤乙方之名，乙方便记得……自己**还剩**一个名字。 | **声音能量**累积（L2–3） |
| 十 | 乙方偶有一瞬清醒，说了不该说的话——事后一律不认。 | L2（首次触发「清醒一瞬」后） |
| 九 | 此约无期限。乙方不许谈「还剩多久」。 | L3（呼应「永远只显示第 N 天，没有分母」） |
| 十一 | 甲方荒废己身之时，已显之约将重新 █████。 | **首次荒废/衰退事件**后（L2+） |
| 十二 | 本约履完之日，即 █████ 重归之时。 | L4（最模糊，指向 L5 的永久留白） |
| **七** | **（终显 · 情感锚，见 §1.2）** | **L5 深度养成解锁 或 离去时** |

### 1.2 第七条 · 终显（整套碎片的落点）

**主选（canonical）：**
> **第七条**
> 你若终究停下——不再走，不再好好睡，不再抬眼看真的东西——
> 我便照着这约，一条一条把你忘掉。
> 先忘你走路的样子，再忘你睡着的样子，
> 最后……忘记你替我起的名字。
> 到那时，约就算履完了，你不欠我什么。
> ——别难过。我本来，也是被这样送来的。

- 全文**唯一一句 lore 私语**是最后一行「我本来，也是被这样送来的」（**被送来** = 对来历的唯一
  斜向暗示，永不解释）。
- **双态解锁**（对应 bible §9 待定 4）：
  - **奖励态**：深度养成到 L5 时解锁——逻辑是「你不会停了……所以我现在能告诉你了」。
    好玩家**用坚持换来真相**。
  - **终局态**：若 Pibo 真的离去，这条**在离去画面显影**，措辞略变（把「你若停下」改为
    「你到底还是停下了」），此时你已听不到回音。多数玩家二选一，**很少两者都见到**。

**备选（更暖，留档备用）：**
> 最后我会忘记的，是你曾经好好活过的样子。
> 可我更希望——到那天，是你先不再需要我，而不是我先走。

> 敲定第七条 = 敲定整条情感线，其余碎片都朝这个落点埋。

## 2. 揭示层 L0–L5（无年代神话向，非科幻向）

真相**永不被直接告知**，玩家从碎片自行拼出**情绪**。每层只给残片，不给结论。

| 层 | 碎片透露的 | 玩家会开始怀疑 | 门控 |
|---|---|---|---|
| **L0** 表面 | 一个怪可爱的东西，签了约要你照顾身体，不然它会没 | （只是只怪东西） | 首启 |
| **L1** 不属于这里 | 它把手机认作别的东西，怕镜子，不认识电梯 | 它不是本地的 | 任意能量入门 |
| **L2** 不属于此刻 | 呓语漏出「……还没……发生……」「后来……」 | 它来自别的时间 | 多类能量累积 |
| **L3** 萎缩之事 | 碎片提到「停下来的人」「把思考交出去的人」「不再走路的城」 | 某处出了大事 | 持续养成 |
| **L4** 来历与使命 | 约定=某种托付；花其实是「█种」；它是「被送来的」 | 它为某事而来 | 长期多维养成 |
| **L5** 永不闭合 | 谁送的它、成没成、它回去要付什么——**全部留白** | ……（自行想象） | **从不完全解锁** |

> **红线**：L4/L5 靠玩家脑补，产品**从不盖章**。像魂系「到底发生了什么」永远是社区在吵——
> 这份不确定就是耐玩与讨论度。**任何文案都不得出现** AI / 机器人 / 年份 / 抵抗军 / 元年 等词。

## 3. 碎片文案池（初稿，可续写）

### 3.1 记忆碎片（喂能量/拔毛偶掉，进「记忆馆」收藏；魂系物品描述体）
- 「一枚还温着的东西。它说，这是『最后一个自己走完全程的人』落下的。它不记得那是谁。」
- 「半页纸，字迹被水泡过：『……只要还……愿意累……就还来得及……』后面没了。」
- 「一颗干瘪的种子。它说这种花以前『到处都是』，现在它只在你睡够的那天见过一次。」
- 「一只旧鞋的印子，拓在石头上。它盯着看了很久，说：『这个……是往前的意思，对吧。』」
- 「一段哼不成调的音。它说有人以前用这个哄它，可它想不起那人的脸，只记得『很暖』。」
- 「一块发凉的玻璃。它把脸贴上去又移开：『别把眼睛……留在这种东西里……啵。』」
- 「半枚徽记，缺了一角。剩下的部分像一株刚破土的芽。它不肯说这是谁的记号。」

### 3.2 Pibo 呓语（深眠 / 发呆泄露；破碎、环境音式）
- 「……他们后来……都不太走路了……（呼）……喂，你……还走吗？」
- 「……不能都……交出去啊……（呢）……留一点……给自己……」
- 「……我记得有光的……在很远……很久……以后……」
- 「……你睡着的时候……我好像……差点想起来……又忘了……啵。」
- 「……那不是我的错……我只是……来晚了……（很小声）」
- 「……名字……名字还在吗……（翻身）……嗯……还在……」

### 3.3 拍照误读（拍现代物件偶发；俏皮埋料，绝不点破科幻）
| 拍到 | Pibo 的误读 |
|---|---|
| 手机 / 屏幕 | 「……这个……会把你的眼睛留在里面……啵。」 |
| 跑步机 | 「刑具？……不对……是『自愿的』那种……嗯？」 |
| 电梯 | 「它替你上去？……那你的腿……做什么用……」 |
| 镜子 | 「（后退）……里面那个别信……它不流汗……」 |
| 包装食物 | 「这个……很久很久以前……是活的吗？」 |
| 汽车 / 代步工具 | 「坐上去……就到了？……那中间那段路……谁替你走了……」 |

### 3.4 地图遗迹（世界地图凑近查看；环境叙事）
- 半埋的碑，凑近才显字：「**献给还记得怎么用身体的人**」。
- 一台锈住的机器，缠满藤：Pibo 绕道走，「……这个以前……什么都替人做……连累都替了。」
- 一排空椅子面朝同一个方向，正对一堵空墙。它站了很久，没说话。
- 路边一块界碑，一面写「往前」，一面被磨平了。它总在这儿停一下才继续溜达。

## 5. 记忆恢复度模型（内部量，永不外露）

```
MRI（Memory Recovery Index）= Σ 各类能量事件的加权累积（深度，非天数）
```
- **加权**：鼓励「多维度」而非「单点刷」。建议单类能量对 MRI 的边际贡献**递减**，
  多类并进才能推进到 L3+（呼应「四类能量并进」）。
- **分层门槛**（示意，可调）：L1 入门即达；L2 需 2+ 类能量各有基础累积；
  L3 需持续（如多周）多维；L4 需长期多维 + 名字线（第八条）已显；L5 从不完全解锁。
- **乱序**：同一层内可掉的碎片**随机**出现，形成拼图感。
- **无分母**：UI 永远只显示「与 Pibo 相识第 N 天」；MRI / 层级 / 碎片总数**一律不外露**。

## 6. 衰退时的碎片行为（接 bible §6）

- **触发**：连续能量不足达阈值（沿用旧 PRD：~3 天低能量 → glitch）。
- **表现**（按严重度递进）：
  1. 已显影的约定条文**重新模糊**（第十一条先应验）；
  2. 记忆馆里的碎片开始**风化**（视觉剥落 → 描述变残 → 消失）；
  3. Pibo 呓语转向「刚想起点什么……又没了」；
  4. 若走到离去：第七条**终局态**显影，记忆馆几近清空。
- **恢复**：完成一次对应健康任务即可止损（沿用 0603 §5 的「一个健康任务复原 glitch」）；
  已风化消失的碎片**是否找回** = bible §9 待定 2，需拍板。
- **绝不控诉**：全程世界事实陈述，无「你害的」。

## 7. 续写风格指南（给后续写碎片的人）

1. **先问过 L 层**：这条碎片属于哪一层？它只能暗示该层允许的东西，不能越层剧透。
2. **物品/环境体**：像魂系物品描述——**冷、短、带一个说不清的往事**，句末常留残缺。
3. **Pibo 说话**：含糊音节 + 傲娇 + 偶尔一句突然的重量，然后否认。用「……」「啵/呢/呼」断句。
4. **禁用词**：AI、机器人、年份、抵抗军、元年、时间旅行、科技名词、任何能一句话概括真相的词。
5. **温柔别明说，残酷平静说**：这是全篇唯一的手感准绳。
6. **每条都能独立成立**：玩家乱序撞见，单看要有味道；合看才拼出情绪。

## 8. 落地优先级（建议）

1. **敲定第七条**（§1.2 主/备选二选一）——一切的锚。
2. 重构 `PiboStoryline`：从线性章节 → **碎片池 + 约定条文显影 + MRI 门控**。
3. 先接**拍一拍掉碎片 / 显影约定**（最小闭环，代码已有 25% 钩子）。
4. 记忆馆 UI（可复用被移除的图鉴外壳）。
5. 拍照误读接入现有 `SubjectClassifier`。
6. 衰退「风化」与第七条终局态（接 glitch/死亡弧时一并做）。
