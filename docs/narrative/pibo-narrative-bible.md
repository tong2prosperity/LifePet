# Pibo 叙事圣经 · 失忆 × 约定 × 碎片叙事

> **状态**：这是 Pibo **叙事/世界观的当前唯一真源（narrative source of truth）**，取代此前的
> 「异世界种花小精灵 + 魔丸→傲娇→伙伴 三阶段人格」框架，也**不采用**「AI 抵抗军科幻时间线」作为

## 0. 一句话内核

> 一个失忆的小东西坠到此刻，身上只剩一个本能——**别让你睡死在自己的身体之外**，而它正是靠这个活着。
> 它从哪来？碎片只给你一种**情绪**，永远不给你一个**答案**。眼下唯一确定的是：你俩被拴在一起，
> **你好好活，它才不散。**

**这不是养宠物，是两个都快撑不住的存在，互相成为对方活下去的理由。**

---

## 1. 三根支柱（一切设计从这里长出来）

### 支柱 1 · 性格恒定
Pibo 永远是那个**傲娇、嘴硬、只顾头顶花、说话含糊（啵 / 呢 / ……）**的样子。它**不会「长大变温柔」**。
- 变的不是性格，是**它想起来的东西**和**你俩之间的信任**。
- 含糊的语言**不是「魔丸阶段」的设定**，而是**失忆的症状**——它连人类的话都记不全，只能碎着说。
  一石二鸟：既保留了现有的乱码音节文案，又给了它一个叙事理由。
- **迁移含义**：旧文档的 `魔丸→傲娇→伙伴` 三阶段人格软化线**作废**。人格是一条水平线。

### 支柱 2 · 失忆（这是结构装置，不只是背景故事）
它坠入此刻，**忘了一切**：自己是谁、从哪来、为什么。本能里只剩两条：
1. **必须和一个人类立一个「约定」**；
2. **帮 TA 照顾好身体**——因为它模糊地知道，**照顾不好，它自己也会消失**。

失忆同时干**四件**别的设定办不到的事：
| 它顺手解决的问题 | 怎么解决 |
|---|---|
| 首日不能塞世界观 | **连 Pibo 自己都不知道**，所以无需解释 |
| 说话为什么含糊 | 失忆的症状 |
| 叙事进度绑什么 | **「记忆恢复」= 健康行为深度**（见 §5），焊死在核心机制上 |
| 用户的情感站位 | 从「饲主」变成**「和它一起从零拼真相的同谋」** |

### 支柱 3 · 魂系碎片叙事（唯一手法）
**没有过场动画，没有章节，没有「第 N 天剧情」。** 真相散成碎片，藏在物品描述、环境细节、
呓语、约定条文里，**玩家自己拼，而且永远拼不全**——留白就是魂系的灵魂。

## 2. 被砍掉的与被保留的（关键取舍，务必读）

产品曾讨论过一条「AI 抵抗军把时间旅行生命体送回来打 AGI」的科幻时间线。**我们保留它的洞察，
砍掉它的外壳**，原因四条：

1. **具体化 = 去魅**。魂系耐嚼是因为真相**无法被一句话概括**。「未来抵抗军的时间旅行生物兵器」
   一旦拼出，就塌缩成一个认得出的科幻套路，谜就死了。
2. **绑定现实 = 速朽 + 站队**。写死「GPT-3 / 2025 / AI 统治」会把虚构钉在一段高速过期、
   且高度对立的现实话语上，还逼产品表态「AI = 敌人」。
3. **调性反向**。反乌托邦的引力永远指向恐惧和高压；产品要的是温柔。
4. **「为什么该在乎健康」不该被论证，该被感受**。用文明论回答它是用力过猛。

**替换物 · 无年代的「失去身体」神话**：
> 在某个地方、某个时候，人们慢慢**不再住在自己的身体里**，于是丢了某样东西。
> Pibo 带着「别让这事发生」的本能来到你身边——但连它自己都记不清那是什么。

这个版本**更强**：真正的敌人不是「2050 的 AGI」，而是**此刻就普适**的东西——屏幕、久坐、
把注意力外包出去。它对 2026 年正在刷手机的用户**直接成立**，**永不过期、永不站队、永远留白**。

> 一句话：**把「AI 未来战争」这个会过期的科幻外壳，换成「人正在丢掉自己的身体」这个此刻就成立的神话。**

**保留清单**（不受上面影响）：真实健康数据=能量=生死的核心循环、傲娇不说教的语气、
花↔能量的可视隐喻、glitch/生病/离去的衰退弧。

## 3. 核心隐喻：花 = 你「还活着的那部分」

头顶的花不是装饰，是**你身上仍然住在身体里、仍然清醒的那一部分**的具象。
- Pibo 拼命想让它开，因为那是它此行**唯一认得**的东西。
- 你睡好、走动、抬眼看真东西 → 花有精神；你荒废自己 → 花萎。
- 花照旧是核心视觉隐喻（温暖、一眼懂、代码已有 `growthStage`）。

## 4. 表达系统：五个载体 + 三层声音

### 4.1 五个碎片载体（真相只从这些缝里渗出）
| 载体 | 承载 | 绑定机制 |
|---|---|---|
| **约定条文**（涂黑 → 显影） | 主线骨架（非线性） | 照顾自己 → 逐条显影 |
| **记忆碎片**（魂系物品描述） | 一段冷冷的往事 | 喂能量 / 拔毛偶掉 |
| **Pibo 呓语** | 环境音式的破碎真话 | 深眠 / 发呆泄露 |
| **拍照误读** | 俏皮又埋料 | 拍现代物件偶发 |
| **地图遗迹** | 环境叙事：不属于此世的物件 | 世界地图凑近查看 |

完整文案池见 [pibo-storyline-fragments.md](pibo-storyline-fragments.md)。

### 4.2 Pibo 的三层声音泄露（性格恒定，变的只是漏出多少）
1. **日常傲娇碎嘴**（表面）——绝大多数时候。
2. **睡话 / 发呆漏真话**（裂缝）——深眠、idle mutter。
3. **「清醒一瞬」**（极罕见）——突然说出一整句有重量的话，然后**立刻矢口否认**。

### 4.3 玩家拼的是「情绪」，不是「谜底」
刻意设计成**永远拼不圆**。L5 层（§见 storyline）**从不闭合**。

## 5. 进度轴 = 记忆恢复度（不是天数，不是人格）

- **记忆恢复度（Memory Recovery Index）= 四类能量的累积深度**（睡 / 动 / 认知 / 声音），
  不是相处天数，不是人格阶段。
- 你越照顾自己 → Pibo 得到越多能量 → 记起越多 → 你多拼到一角情绪。
- **懒的人永远停在表层**——真相是给「真在照顾自己」的人的奖励，**却一句「你该运动」都不用说**。
- 碎片**乱序掉落**，自然形成魂系拼图感（先捡到一角看不懂，后来补上另一片才恍然）。
- **没有分母**：UI 永远只显示「与 Pibo 相识第 N 天」，绝不显示 N/总数。恢复度是内部量，不外露。

---

## 6. 衰退叙事 = 记忆散失（冷静陈述，绝不控诉）

接 glitch / 生病 / 离去弧，但用魂系的冷静：
- 长期荒废 → Pibo 能量枯竭 → **已显影的条文重新模糊、记忆碎片从收藏里「风化」消失**。
- 表现是**世界事实，不是控诉**。它不会说「你害的」，只会某天呓语：
  「……刚才……我想起点什么的……又……没了……啵。」
- **它真的离去后**，留下一张**写完了的约定**——那条空了很久的第七条此刻才显影，
  而你已听不到回音。（离去 = 最后一块碎片，代价留白。）

---

## 7. 语气红线（任何新文案都要过这关）

- ❌ 不催（「你该运动了」）、不问责（「你害它消失」）、不卖惨、不写完整鸡汤、不出现科幻专有名词。
- ✅ 傲娇嘴硬（「花没精神……才不是担心你」）、把真相藏进物件让你自己撞见、
  **所有沉重都用轻描淡写说出口**。
- 魂系精髓：**残酷的事，平静地陈述；温柔的事，别明说。**

## 8. 与代码 / 机制的接口（迁移说明）

| 现状（代码） | 目标 |
|---|---|
| `Story/PiboStoryline.swift` 线性「第一章·坠落」+ 顺序揭示 | 改造成**「记忆碎片乱序掉落 + 约定条文显影」**，按恢复度分层门控 |
| 拍一拍 25% 揭示下一条 clue | 改为掉一枚**记忆碎片**或**显影一条约定**（乱序） |
| `growthStage`（mystery⇄sprouted） | 语义从「人格阶段」改为**「记忆恢复度」的可视锚**；性格不动 |
| 四类能量 → 花 | 各绑一类碎片载体（见 §4.1 / storyline 的映射表） |
| 图鉴 / 花品种（display-only） | 可复活成**记忆馆 / 碎片图鉴**，每条描述是一片 lore |
| 世界地图（Godot 原型 / 未来主 UI） | 加**遗迹环境叙事** + 荒废时 glitch 关闭 |
| glitch / 生病 / 离去弧（TODO） | 接「记忆散失」叙事（§6） |

> 注意：**语气池、乱码音节说话方式、能量→花 都保留**；改的是**框架与故事线组织方式**，不是重写表层。

## 9. 待定 / 留白清单（留给产品拍板）

1. **第七条最终显影文案**（整套碎片的情感锚）——storyline 已给主选 + 备选，需最终敲定。
2. **记忆碎片是「可永久收藏」还是「会风化消失」**——关系到衰退惩罚的锋利度（魂系倾向会失去，
   但对健康 app 可能太狠）。
3. **声音能量（呼唤名字）是否独占一条最私密的碎片线**——它失忆，唯独……记得有人喊过它？
   可留作全篇最后的温柔（对应约定第八条）。
4. **约定第七条是「仅在离去时显影」还是「深度养成到 L5 也可解锁」**——建议双态（见 storyline §1）。
