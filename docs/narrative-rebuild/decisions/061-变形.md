# 决定 061：变形

> 日期：2026-10-20
> 状态：已批准（2026-10-20，用户：「你理解的变形是非常合理的，根据你的变形理解开始实现」）
> 依据：用户 2026-10-20 提出——Pibo 是一种变形怪，在地球上可以变成任意形状，这个能力慢慢觉醒；用户骑车 Pibo 就变成自行车，会说话，会变回去，有时候又不知道怎么变回去；变形能力从一开始就要体现出来
> 范围：修订 059 一页正史；在 060 生活回声之上；Core 规则与像素表现；iOS 不补齐（沿用 057）

## 1. 正史补充

059 第 6 节一页正史追加一段：

> Pibo 的身体能变成别的样子。家里的人本来都会，只是在穹顶里什么都不用自己做，这个本事几代人都没用过，差不多忘光了。到了地球，它和 `bo` 一起，一点点醒了过来。

麻薯形是 Pibo 最舒服的「休息形态」，不是唯一的样子。它知道自己是谁（059 不变），只是身体在地球上还不熟。

## 2. 觉醒四阶段

按相处天数（身份 `birthDate`，第 1 天起算，与足迹、陪伴同一个定义）：

| 阶段 | 相处天数 | 能做到什么 |
| --- | --- | --- |
| 0 漏出来 | 第 1 天起 | 控制不住：打喷嚏会「噗」地变成一块石头或一朵蘑菇，几秒后弹回来 |
| 1 想变 | 第 2 天起 | 你做了某件事，它想变成对应的东西，鼓起劲试一下，变不出来，改成模仿（060 的回声） |
| 2 学你 | 第 4 天起 | 真的变成你那天做的事里的东西；变完有时候变不回去 |
| 3 熟练 | 第 10 天起 | 同上，变不回去的情况少了 |

变成的东西只来自真实数据（060 的回声事实），没数据不变，不编。

## 3. 形态

| 你的生活（060 回声） | Pibo 变成 |
| --- | --- |
| 跑步、今天走了很多 | 一只跑鞋（在空地上蹦着跑） |
| 骑行 | 一辆自行车（在空地上骑，点它会响车铃） |
| 游泳 | 一条小鱼（有池塘在池塘里，没有就在草地上扑腾） |
| 瑜伽 | 一棵小树 |
| 高强度 | 一根弹簧（原地弹） |
| 睡得很好 | 一个枕头 |
| 很晚还醒着 | 一盏小灯 |
| 刚吃过饭 | 一只饭碗 |
| 做了正念 | 一块安静的石头 |
| 打喷嚏（阶段 0 起） | 石头或蘑菇，几秒就弹回来 |

徒步、冷却、哈欠、早操、烤蘑菇继续用 060 的模仿动作。

**认得出是 Pibo**：每种形态都保留那双点点眼和头顶的 `bo` 叶。读屏读作「Pibo 变成了自行车」。

## 4. 变不回去

阶段 2 起，变形结束时有时变不回去（阶段 2 约三次一次，阶段 3 约八次一次，由 Core 用种子决定）：
- 它停在那个形态，扭来扭去，说一句「诶？变不回去了……」；
- 你在它身上双击就是帮它一把，「噗」地变回来，它道谢；
- 你不管它，二十秒后它自己弹回来，也说一句；
- 不催促、不制造愧疚，不计入任何奖励或惩罚。

变形期间（没卡住时）双击它，形态自己会有回应（车铃、鱼吐泡泡），不走拍一拍文案。

## 5. 从一开始就看得到

- 阶段 0 第一天就会因为喷嚏漏出来；
- 后续（不在本轮）：首次引导第一眼是一块会眨眼的石头，「噗」地变回 Pibo；捉迷藏时变成森林里的东西；第二季旧笔记里加一页变形笔记。

## 6. 职责

- **Core**（`transform` 模块）：阶段阈值、回声到形态的映射、喷嚏变什么、这次是变成／只是试试、变多久、会不会卡住、卡住多久自己弹回；
- **平台**：每种形态的像素图、「噗」的过渡、卡住时的扭动、双击命中、台词呈现与读屏文字。
