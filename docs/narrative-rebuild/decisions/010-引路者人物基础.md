# 决定 010：引路者人物基础

> 决定日期：2026-07-27  
> 状态：已拍板

## 与 Pibo 的关系

引路者以职业导师为关系骨架，长期照看、训练并送 Pibo 执行第一次独立取火任务，但不是 Pibo 的明确父母。

这段关系同时具有职业责任与私人关心：

- 引路者欣赏 Pibo 的认真，也知道它会为了证明可靠而逞强；
- Pibo 希望获得引路者的专业认可，也把它视为故乡最具体的情感连接；
- 引路者盼望 Pibo 带回足以维持故乡的 `bo`，也真心希望 Pibo 平安返回；
- 它不会因为私人感情把 Pibo 置于故乡其他生命之上。

## 身份

引路者是资深取火者与栖居系统维护者。它亲历或直接继承了漫长避难史的生命代价，知道封闭系统为何必须稳定运行，也知道改变失败可能造成真实伤亡。

它相信：负责首先是让仍然活着的人安全度过今天。

## 恒定性格

- 稳定、耐心、极少夸大承诺；
- 尊重证据和风险，不轻易被希望说服；
- 通过准备、校验与承担后果表达关心；
- 不嘲笑年轻人的理想，但会追问由谁承担失败代价；
- 能承认旧方案不是终点，却拒绝用未经验证的新方案直接替换生命支持系统。

引路者与 Pibo 的性格相近：两者都认真、直接、通过行动表达关心。主要差异来自承担的位置：Pibo 离开系统后看见了另一种生活，引路者每天都必须对系统内的生命负责。

## 私人愿望与恐惧

引路者同时希望：

1. Pibo 平安回来，并成为能够自行判断的取火者；
2. Pibo 不要因一次个人经历轻率动摇所有人的安全。

它最深的恐惧不是失去权威，而是自己同意理想化试验后，再次看见避难时代的伤亡。

## 与 Pibo 的关系弧

1. 出发前，引路者负责训练与校验，Pibo 努力证明自己可靠；
2. 失忆后，Pibo 忘记引路者，却保留由它训练形成的习惯；
3. 记忆恢复时，引路者先通过动作、工具和训练片段显影；
4. 重新连接后，引路者要求 Pibo 完成取火并返航，成为旧使命最有善意的声音；
5. Pibo 不愿把地球登记为永久取火点，引路者要求它提出替代方案和风险边界；
6. Pibo 返乡后，引路者不会被彻底说服，只同意与 Pibo 开始有限、可验证且不威胁整体系统的修复试验。

## 结局边界

故事不以“年轻 Pibo 证明导师完全错误”收尾。引路者与 Pibo 都只看见部分现实；返乡后的有限试验代表双方开始共同承担改变，而不是理念争论已经结束。
