# 058：Pibo 的一天

日期：2026-10-19。状态：用户已批准，HarmonyOS 先行（分支 `feature/pixel`）。**iOS 不补齐**（用户决定：「ios不需要补齐」）。批准原话：「完整做pibo的一天，另外，场景是否可以换，森林是否可以有动态，周边的物体是否可以互动，都需要思考。」此前反馈：「你还是完全沿着之前固定的内容，只是做了像素化么？」

## 背景

- 057 的像素首版只把原有行为像素化：Pibo 站在画面中央，按六状态播放固定动作，森林是背景，装饰只是摆件。
- 用户要的是一只**过自己日子**的 Pibo：会在空地里走动、去不同的地方做不同的事，会注意到你，会因为你走路而出门探险。

## 决定

### 1. 地点

- 空地上的每个物体都是一个**地点**：苔藓窝、大树、高草、林边、路牌，以及已放置的装饰（蘑菇凳、名牌、石头堆、花圃、风车、月亮灯、池塘、秋千、篝火、帐篷、吊床、观测仪），下雨时还有水洼。
- 场景共三个：林间空地（Lv.1）、小溪边（Lv.3）、山坡（Lv.6）。小溪有跳石、倒木、芦苇、溪岸；山坡有花田、孤树、大石、山顶。
- 装饰、吊床与观测仪只在林间空地。
- **换场景走路牌**：点路牌打开森林地图，选一个已开放的场景，Pibo 从林边走出去，再从另一个场景的林边走进来。不提供横向滑动切换（首页仍是固定竖屏，`check_port` 禁止水平拖拽）。

### 2. 按状态与环境过日子（规则在 Core）

| 状态 | 会做的事 |
| --- | --- |
| energetic | 跑、荡秋千、追甲虫、绕风车、踩水 |
| stable | 散步、坐凳子、整理石头、浇花 |
| tired | 慢走、坐下、靠着大树打盹 |
| sleeping | 按吊床、帐篷、苔藓窝的顺序找地方睡，偶尔说梦话 |
| waking | 伸懒腰、洗脸 |
| dataUnknown | 坐在路牌边，头上一个「？」 |

- **天气和时间**：下雨撑叶子伞、跳水洼，雨停后可能出彩虹；黄昏等甲虫；夜里看星星或烤篝火；冬天下雪积雪；秋天红叶落叶；春天开花飘花瓣。
- **小溪和山坡的专属活动**：打水漂、看鱼、走倒木、跳石头、闻花、滚下山坡、在山顶眺望、追蝴蝶、玩雪。
- 选择由 Core `day_choose` 按状态、天气、时段、场景加权挑选，并避免连续重复。平台只负责走路、动作姿态和渲染。

### 3. 森林自己在动

松鼠、鱼、蝴蝶、鸟、云、雾、落叶、花瓣、雪、彩虹按季节、天气、时段出现（Core `day_ambient` 返回位掩码）。点大树松鼠会探头，点水面鱼会跳，点花会开。**每个能点的东西都会自己回应**，不管 Pibo 去不去。

### 4. 邀请 Pibo 去一个地方

- 点一个地点就是邀请 Pibo 过去。Core `day_invite` 按状态和熟悉度决定答应还是婉拒：
  - 睡着时不去；
  - 累了不去热闹的地方，老朋友档会不情愿地坐下；
  - 初见档偶尔害羞；
  - 正在忙的时候说一声。
- 每天的邀请次数按语气档封顶：3／6／10。
- Pibo 已经在那个地点时，再点一次就说那里的一句话。
- 拍一拍不受影响：在哪儿都能拍。

### 5. 注意到你

回到首页时，Pibo 转身回应（Core `day_greet`），回应方式按熟悉度分档：

- 初见：远远地探头看一眼；
- 熟悉以后：跑过来，有新发现就拿给你看；
- 老朋友：离开 30 分钟以上回来时，**每天一次**会躲进某个地点，等你找。
  - 找到有爱心；
  - 点错了，它会笑你；
  - 25 秒没找到，它自己出来。

### 6. 你走路，Pibo 也出门

- 当天步数跨过 2000／5000／8000／12000 时，Pibo 依次出门去草坡、松林、河边、山顶（Core `explore_trip`）。
- 每次带回一样东西，共 24 种，按目的地和季节出现，新东西优先。东西放进空地边的篮子；点篮子打开**收藏架**，没找到的显示剪影。
- 出门时 Pibo 从林边走出画面，过一会儿带着东西回来。
- 你不在时完成的出门，会在下次回来时变成离开摘要里的**散步日记**，例如「你走了 8000 步，我走到了河边，捡回一根羽毛」。步数只放在事实小字里。
- 发现记录和日记只存在本机，不上传，不进日志和埋点。

### 7. 文案边界

沿用 057：不催促、不制造愧疚、不评价身材、不比较、不下医学判断；台词里不写数字；捉迷藏台词只对老朋友档开放。由 `tools/test_day_copy.mjs` 强制执行。

## 不做

- 不加横向滑动切换场景，也不做多个首页；
- 没有走路就不会出门，不伪造步数；
- 不为出门、捉迷藏、邀请发系统通知；
- 不加新的货币，收藏不能出售，没有连续天数。

## 影响

- **Core**：`pibo-core 0.29.0` 新增 `day.rs` 与 `explore.rs`，以及对应的 C ABI。
- **HarmonyPibo**：
  - 像素舞台由导演按节拍驱动 Pibo；
  - 新增地点、氛围层、收藏图章、森林地图和收藏架；
  - 新增日志 tag `Day`。
- **iOS**：不补齐（用户决定）。
