# 050：散步涂鸦延后至 MVP 之后

- 日期：2026-09-09
- 状态：用户已批准；原话「这个版本隐藏,mvp不做这个功能了.」

当前 MVP 不提供散步涂鸦。此决定覆盖决定 025、046 与旧首发检查点中要求该功能首发开放的部分。隐藏首页入口、足迹中的涂鸦卡与创建空状态，以及风铃中的收藏、重播和跳转入口；Debug 与 Release 一致，不用调试旁路恢复。

保留已实现代码、历史记录和 Core 任务／几何／奖励合同，不删除用户数据，不改变共同物件所有权、成本或解锁顺序。风铃相关功能显示暂未开放，不承诺本版可以创作或重播。物件价值与链路重排另行决定，不在本次隐藏中隐式更改。

HarmonyOS 先实现；iOS 表现层本轮不修改，仍需按 Harmony-first 记录关闭所有对应入口及 Debug 启动参数旁路。后续重新开放必须先确认产品范围，再完成定位、真实户外完成与保存、生命周期和回到森林体验验收。
