# 决定 020：核心事件载体选择原则

> 决定日期：2026-07-29  
> 状态：已拍板

## 四类叙事语言

| 内容类型 | 优先表现形式 |
|---|---|
| Pibo 与用户此刻正在经历的事情 | 主页实时动作、环境和物件变化 |
| 故乡历史与过去记忆 | 信号进入后展开的漫画、静态分镜、短片或组合形式 |
| 授权、约定和隐瞒后的选择 | 独立对话与明确交互 |
| 抵达、原生 `bo`、返航等重大转折 | 镜头控制更强的短动画或视频 |

## 选择原则

1. 发生在“现在”的关系行动优先在主页直接表现，不能把当前关系全部切到漫画或视频中讲述；
2. 漫画和档案主要表现用户无法亲历的过去；Pibo 此刻作出的关键选择仍需在当前空间中发生；
3. 视频是重要节点的强调手段，不是所有事件的默认模板；
4. 即使事件中播放视频、漫画或独立对话，结束后也必须回到已经发生变化的主页，让事件成为空间中的事实。

## 七阶段的总体节奏

- 错误连接：主页异常与互动约定；
- 互相利用、无用记录：以主页原生事件为主；
- 故乡显影：主页变化结合漫画、记忆或短片；
- 真相裂缝：档案揭密结合当前空间中的正面选择；
- 共同改写使命：故乡通信结合原生 `bo` 的空间事件；
- 从容告别：主页共同事件、返航短片与最后记录。

具体事件采用哪一种载体、时长和制作方式，在逐事件深化时确定。
