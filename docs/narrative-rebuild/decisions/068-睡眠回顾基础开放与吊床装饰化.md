# 决定 068：睡眠回顾基础开放与吊床装饰化

> 决定日期：2026-10-21  
> 状态：已批准（用户明确要求合理实现）  
> 修订：046、057 中吊床授予睡眠回顾与睡醒通知、保持旧解锁流程的条款。

- 睡眠回顾从首次使用起提供，不依赖吊床、bo、等级、物件所有权或放置状态；足迹继续可查看历史睡眠。
- 睡眠总结提醒同样是基础能力；仍遵守用户的提醒开关、系统授权、每日去重和真实睡眠记录条件。前台直接展示回顾，后台同步后发送通知，不承诺刚醒即通知。
- 无授权、无数据或同步未完成时不伪造睡眠记录，不生成成功回顾或通知。
- 吊床是 bo 购买的森林装饰，放入森林装饰目录，不显示场景中的未购灰态，也不提供场景中的解锁入口。
- 沿用 Core 的吊床稳定 ID、1 bo 价格、原所有权和幂等购买合同；购买后可放置或收起，原已购用户默认放置、不重复扣费。
- 吊床仍可作为 Pibo 的休息落点和最近睡眠回顾的便捷入口；收起、未购均不影响睡眠回顾或通知。
- Core 提供基础能力合同；HarmonyOS 先实现与验证。iOS 表现本轮不修改，待按 Harmony-first 记录补齐。
