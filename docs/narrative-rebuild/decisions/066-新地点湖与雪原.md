# 决定 066：新地点——湖与雪原，以及地点内的纵深（草案）

> 日期：2026-10-21
> 状态：**草案，待批准**（2026-10-21 用户：「新地点新玩法后续写成决定」；本文只是提案，批准前不进 Core、不实现）
> 依据：像素重构后的玩法检查——三个场景已经能住人，但等级再往上没有新地方可去；用户要「更大的地图」，而 058 不允许横向拖动
> 范围：修订 058 第 1 节（场景只有三个）；需要新的 Core 标签；iOS 不补齐（沿用 057）

## 1. 为什么不做可以拖动的大地图

- 058 规定首页是固定竖屏，不加横向滑动；`check_port` 也会拦住水平拖拽。
- 地图越大，Pibo 越常不在画面里。Pibo 的核心是「打开就看到它在过日子」，不是「去探索的游戏」。

所以「变大」按两个方向做：**往后开新地点**，以及**每个地点往里有纵深**。

## 2. 两个新场景

| 场景 | 开放等级 | 地点 | Pibo 的专属活动 |
| --- | --- | --- | --- |
| 湖边 | Lv.10 | 栈桥、芦苇荡、湖心小岛（只能看）、浅滩、柳树 | 坐在栈桥边晃脚、在浅滩踩水、看湖面的倒影、傍晚看日落 |
| 雪原 | Lv.15 | 雪坡、冰面、松树、雪洞、石堆 | 滑下雪坡、在冰面上滑、钻雪洞、看自己的脚印 |

- 入口不变：仍然点路牌打开森林地图，选已开放的场景，Pibo 从林边走出去，再从另一边走进来（沿用 058，过场用 065 的横向卷轴）。
- **雪原四季都有雪**。它是山后面的高处，不受季节影响；空地、小溪、山坡的季节规则不变。
- 天气照常：湖边下雨时湖面起涟漪，雪原下雪时更厚，晴天的雪会反光。
- 两个场景各开放一两件专属装饰（例如湖边的小木船坞、雪原的雪橇），沿用 065 的「只在自己的场景出现」，具体名单、成本、等级随 Core 实现时一起定。
- 捉迷藏、变形躲藏、摆收藏品、食物贴纸垫的规则不变：垫子仍然只在空地；伪装形态按场景各给两种（湖边：石头或荷叶，雪原：雪球或石头）。

## 3. 地点内的纵深

- 每个场景分成前景、中景、远景三层。Pibo 平时在中景活动，有些地点在远景（例如湖心小岛、雪原远处的松林边）。
- Pibo 往深处走时会变小一号、走得更慢，被前景的草和石头部分挡住；走回来时再变回原大小。
- 这是让画面「显得更大」的办法，不加滑动、不加镜头移动。只有原本就在远处的地点会用到。
- 远景地点也能点、能邀请，点击区按现在的最小尺寸放大，不因为画得小而变得难点。

## 4. Core 与平台

- **Core**：`DayScene` 追加湖边、雪原；场景开放等级；新地点和新活动的可用条件、时长与权重；每个地点属于哪一层（前、中、远）；新场景的伪装形态和专属装饰的目录、成本、开放等级。只追加编号，已有编号不变。
- **平台**：场景的画法、各层的坐标与缩放、遮挡、过场、读屏文字。
- 出门（058 第 6 节）的目的地不变，仍是草坡、松林、河边、山顶；湖和雪原只是 Pibo 住的地方，不是出门的终点。

## 5. 不做

- 不做可以拖动或缩放的地图，不加横向滑动；
- 不按场景加货币、连续天数或打卡；
- 不为解锁新场景发系统通知；解锁时沿用现在的森林地图显影。

## 6. 待你确认

1. 开放等级 Lv.10 和 Lv.15 是否合适；
2. 雪原是不是四季有雪；
3. 纵深是否先只在湖边做，验证后再推广到其他场景。
