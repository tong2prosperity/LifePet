# 决定 015：二十一个主线事件与动态空间规则

> 决定日期：2026-07-29  
> 状态：已拍板

## Pibo 对用户的感知边界

- Pibo 可以知道健康能量由哪些授权数据形成，例如睡眠、步行和运动分别贡献了多少、发生在什么时间；
- Pibo 不知道用户为什么散步、是否开心、和谁在一起或正在想什么；
- Pibo 只能把健康数据与自己已经见到的 App 内互动进行对照，不能读心，也不能自行补写用户的现实故事。

## 第一阶段：错误连接

1. 双方建立连接时，签订的是临时合作约定，更深的陪伴关系只能由后续共同经历形成；
2. “错误连接”不是 Pibo 找错了用户，而是 Pibo 错误理解了 `bo`：它以为自己发现的是外部能源，后来才理解那是生命如何生活的结果；
3. 拔下的 `bo` 进入共同库存，由用户决定如何消费，Pibo 无权自行使用；返航因此必须包含用户的主动选择。

## 第二阶段：互相利用

1. 用户最初把 Pibo 当作有趣的健康工具，Pibo 则把用户当作稳定的 `bo` 来源；
2. 第一次库存用途分歧围绕睡眠窝展开：用户选择消费 `bo` 解锁睡眠窝，Pibo 认为这会拖慢返航，但仍遵守用户的决定；
3. 用户关闭 App 后仍在睡眠、步行和生活，健康能量也继续形成。Pibo 由此第一次意识到用户不是供能装置，而是窗口之外独立生活的人。

## 第三阶段：无用记录

1. 用户在没有新产出时仍主动回应 Pibo，一次不为任务收益发生的互动开始改变关系；
2. 悬挂的灯成为“等待”的意象：它不能帮助返航，但 Pibo 后来会在用户不在时主动打开；
3. Pibo 拒绝删除没有任务价值的来访、互动和共同物件记录，第一次主动偏离最高效率原则，但尚不承认这是关心；
4. 单纯打开 App 或使用健康功能不等于“无收益的陪伴”，必须存在一次用户主动回应 Pibo 的非任务互动。

## 功能与故事分离

1. 睡眠、健康数据、拍照、卡路里和历史记录等核心功能在开始使用后即可使用，不由故事阶段解锁；
2. 健康能量达到条件，只让故事事件变得“可以发生”，不会自动推进；用户至少查看或回应一次，事件才真正发生；
3. 每个阶段都必须能够长期停留，并提供固定、可循环的日常动作和台词；它们不依赖 LLM，也不会持续泄露主线；
4. 剧情时间按双方真正发生的故事事件计算，不直接等同于现实经过的天数；长期未打开不会制造愧疚、惩罚或照料责任；
5. 除渐进解锁的养成物件外，故事不锁住核心功能。

## 森林季与动态空间

1. 当前主屏幕是 Pibo 抵达地球、观察不同环境后，因为觉得森林舒服而在自己空间中制造的“森林季”，不是故乡原貌，也不是固定不变的世界；
2. 故乡过去存在类似森林的自然生态，但经历漫长避难后，Pibo 这一代几乎没有真正生活在自然森林中；
3. Pibo 最初只把选择森林理解为“舒服”，恢复记忆后才逐渐明白这种熟悉感并非完全偶然；
4. 核心功能持续可用，但入口、环境反馈和交互方式可以随着故事改变；
5. 故事不仅通过台词和档案表达，也可以改变环境与交互规则。具体变化留到后续呈现阶段设计。

## 第四阶段：故乡显影

1. Pibo 收到故乡信号后开始恢复环境方面的记忆；
2. 用户逐渐看见故乡曾有自然生态，后来在漫长避难中被压缩为高度受控的生命系统；
3. Pibo 恢复记忆后，主动在自己的空间中为用户重现一小部分故乡；重现内容与表现方式暂不拍板；
4. 风铃植物可以在这一阶段出现，但它与环境变化的具体关系留到后续讨论。

## 第五阶段：真相裂缝

1. 原使命包含验证地球生命能否成为可规模化的外部 `bo` 来源；
2. Pibo 最初确实失忆，只有恢复相关记忆后短暂隐瞒任务，才构成真正的欺骗；
3. 翻译恢复后，用户从一直存在的共享任务页中发现真相；
4. Pibo 主动交出连接控制权并提供退出选择。用户在知情后明确选择继续，关系才从互相利用转向共同承担问题。

## 第六阶段：共同改写使命

1. 引路者的反对是合理的：故乡仍有眼前的生存压力，不能因为 Pibo 发现旧判断不完整，就立刻放弃已经维持数代生命的系统；
2. Pibo 自身产生的第一缕原生 `bo` 只是值得验证的异常，既不能支持返航，也不能证明故乡必然能够恢复；
3. 新使命不是让故乡复制地球森林或直接采用地球生活方式，而是在不关闭生命支持系统的前提下，以安全、小范围、可停止的试验验证故乡生命能否重新产生自己的 `bo`；
4. 用户不是拯救故乡的人，而是共同见证证据形成，并在 Pibo 尚无完整答案时仍选择同行的人。

## 第七阶段：从容告别

1. 主线完成、返航库存足够，只代表 Pibo “可以离开”，不会触发倒计时或自动告别；
2. 用户可以继续消费 `bo` 解锁物件，即使因此再次推迟返航；每日健康行为仍可重新积累库存；
3. 风铃植物承担返航前最后一次纯粹的共同经历：它不产生能源、不提供证据，也不提高成功概率；
4. 返航必须由用户与 Pibo 再次明确确认。用户始终不确认，Pibo 就继续留下，不催促、不生病，也不让用户承担照料责任；
5. 返航后结束的是地球共同生活和主线故事，不是永久关闭 Pibo 连接；App 转为低频远程连接，健康功能、历史数据、共同记忆、库存与付费资产继续保留；
6. 结尾先抵达一份跨越距离的延迟记录，说明引路者为有限试验留下位置；远程回复具有明显延迟，不承诺成功、重逢或恢复返航前的相处方式。
