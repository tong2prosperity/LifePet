# 决定 069：像素主线与旧表现退役

> 日期：2026-10-21
> 状态：用户已批准方案并明确要求实施
> 修订：057 的可回退切片、旧表现并存及隐藏保留的工程方式；不改变既有 Core 领域规则。

- 像素版为鸿蒙手机端唯一产品表现；全应用活跃界面沿用现有像素风格，旧舞台和旧 UI 退出运行与打包。
- 当前像素角色、调色板、比例、图标、放大方式和动作节奏作为保护基线。旧 UI 迁移复用现有像素组件，不借机重设计像素版；正文与健康图表保持可读，照片和系统页面保留真实原生呈现。
- 删除 Shadow、小游戏、散步涂鸦、会员购买、风铃、铃兰灯、旧观测仪物件及无消费者的手机—手表投影的客户端 UI 和专用运行链。保留 Core 历史 ABI、账号、余额、物件权属和全部历史数据。
- 旧功能链接安全回到首页，不触发旧业务。旧 JSON 中的退役字段、独立存储键与媒体历史不能因新版保存而丢失。
- 只退役旧渲染，不删除共库的 Core 桥接；正式媒体母版与独立手表呼吸应用不变。
- 每完成一个大的改动，验证后立即独立本地提交，并带同轮 Harmony-first 记录。不得积压到最后提交，不自动推送应用仓库。
- 现有像素金值保持一致；先捕获基线，再修改。未完成真机验证的项如实记录，不用重写金值掩盖退化。
- iOS 不在本轮表现补齐范围；不修改服务端或应用包身份。
