# 决定 013：风铃灯关系意象与主线大纲方向

> 决定日期：2026-07-27  
> 状态：已拍板

> 2026-07-28 修订：本文件将悬挂灯与风铃植物混称为“风铃灯”，并写入未经确认的一枚 `bo` 消费规则。相关部分已由决定 014 修正；二十一个事件方向与非任务关系意象仍有效。

## 二十一个事件方向

接受 `13-二十一个主线事件-v0.1.md` 的整体方向，作为后续逐阶段深化的主线大纲基础。

接受结尾保留一份延迟自动记录：Pibo 离开、窗口安静以后，用户最后收到一次不构成持续通信的记录，知道引路者已为有限修复试验留出位置。该记录提供使命完成感，但不能承诺很快重逢或恢复日常联系。

## 核心非任务物件：风铃灯

采用已有视觉设计“风铃灯”，替代临时示例“小风铃”，作为贯穿用户与 Pibo 关系的核心非任务物件。

风铃灯结合植物形态、微光与风铃感，属于 Pibo 的视觉世界。它可以提供微弱照明、声音或环境氛围，但：

- 不增加健康能量；
- 不提高 `bo` 产量；
- 不恢复返航坐标；
- 不解锁能力；
- 对取火任务没有可计算收益。

因此它不是字面上毫无功能，而是**没有任务价值，却具有生活价值**。

## 关系弧中的四次出现

1. **用户选择**：用户消耗一枚 `bo` 解锁风铃灯，第一次把返航资源用于共同生活；
2. **用户保留**：取火者规则将其标记为非任务物件，用户选择留下；
3. **Pibo 照看**：Pibo 在没有奖励和请求的情况下，主动调整、修复或安置风铃灯；
4. **告别回声**：返航前 Pibo 停下来听它完成一次声光变化；离开后，风铃灯留在栖居地，成为用户仍可看见的共同记忆。

关系意义来自同一物件随时间发生的变化，而不是由台词解释。

## 呈现边界

- 使用预制资源、固定状态和预写内容即可，不依赖 VLM、LLM 或用户现实背景；
- 用户界面不直接称它为“无用之物”，内部可称“非任务物件”；
- 不在后期为风铃灯增加数值奖励，否则会破坏其关系意义；
- 主线只让一个核心物件承担完整关系弧，其他收藏物不批量复制该模板；
- 当前仓库未按“风铃灯/风铃/wind chime”等可检索名称找到对应运行时资源，素材源文件与正式资源 ID 留待呈现阶段核对，不影响本次叙事决定。
