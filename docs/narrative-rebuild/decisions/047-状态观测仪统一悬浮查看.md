# 决定 047：状态观测仪统一悬浮查看

2026-09-06。依据：用户在本轮明确选择“统一悬浮”，要求重新设计仪器并实现。
替代决定 045、046 中状态观测仪持久固定／取消首页卡片的表现约定；不修改经济、准备度或健康合同。

- 已唤醒物件保留稳定森林入口，新的横向镜片仪器配“查看状态”可见标签；未拥有时仍为唯一 next target 的灰态物件，点击沿用唤醒 Half Sheet。
- 点击打开临时悬浮仪器与准备度面板。关闭按钮、面板外点击或系统返回收回面板；关闭后入口恢复可用。不开启旧 pin，不自动恢复上次查看。
- 六状态均允许查看；不佩戴、不拖拽、不叫醒、不改变 Pibo 健康状态、行为 episode 或奖励。
- 仪器与面板使用同一套短展开／收回表现，不按状态制作角色动画。吊床中的角色位置较高时，将同一面板放在下半屏避让。
- 内容继续为今日准备度、睡眠充足度、近期负荷、Core 依据、7 日真实趋势与数据不足／同步中断／权限回退；说明为“查看已有健康记录”，不模拟实时扫描。
- 离开首页或后台即结束查看。减少动态效果直接切换，保留操作和读屏焦点。
- 价格、前置、所有权和 RecoveryStatus 能力沿用已发布 Core；本轮无新共享领域规则，无需 Core 发布或服务端变更。

HarmonyOS 先实现；iOS 尚未补差。具体代码、素材和验证见 HarmonyPibo 的 `docs/harmony-first/2026-09-06-状态观测仪统一悬浮查看.md`。
