# 054：小生物陪伴提问与记忆回响

日期：2026-09-16。状态：用户已批准计划，文案草案待审。批准依据：用户确认第一期范围「app 内 + 服务卡片」，回复形式为「两个选择 + 一个按钮保存用户自己做的回复，先保存在本地」，确定性规则「先发 Core 标签」，文案「我起草，你审」，iOS「Harmony 先行，iOS 记补差」。

## 背景

单人 MVP 收口后，拍一拍是唯一的关系入口，但 Pibo 仍是单向的健康状态镜子：只有用户双击才出字，也不记得用户说过什么。关系感来自双向——Pibo 注意到你、问你、记住、之后提起。本决定把首页从"被动回应"扩展为"偶尔主动、会记住的小生命"，并让既有 `boring`、`coolhide`、`dive` 素材在有明确原因时出现。

## 决定

### 陪伴提示（感叹与提问）

- Pibo 可以主动说一句**感叹**或**提问**。每条提示下方恰好两个预设回复选项；感叹句的选项是回应语气（例如“真的吗”“你尝尝”）。
- 另有「我想说…」入口，打开输入框让用户写一句自己的回复并保存。上限 40 个字符，不允许换行。
- 忽略即气泡淡出：不追问、不催促、不扣任何东西。关闭输入框未保存视为未回答，但不计入忽略退避。
- **回答不给 `bo`、不给任何奖励**，避免把关系变成交易。

### 注意力预算（Core 确定）

- 每次进入首页最多 1 句主动话；每天最多 1 个提示、最多 3 句主动话（天气与环境台词也计入）。
- 与拍一拍共用 3 秒文本冷却。
- 睡眠态、打开浮层、成就弹窗、`bo` 反馈、发芽流程、每日引导期间、已有气泡时不主动说。
- 提示的首选时机是一次拍一拍台词结束后；其次是某时段首次进入首页。
- 连续忽略自动退避：每连续忽略 2 次跳过 1 天，最多跳过 3 天；任何一次回答清零。
- 同一提示至少间隔 7 天才可再问；已经回答且仍有效的偏好类提示不再问。

### 记忆与回响

- 回答保存为本地记忆：提示 ID、选项 ID 或自定义文本、回答时间、过期时间。
- 当日型记忆到本地日终过期；偏好型保留 180 天。
- **每个提示必须写好回响**：每个选项至少一句，自定义回复至少一句以「…」原话引用。
- 回响不在回答的同一次访问出现（距回答至少 10 分钟），受回响自身的冷却与次数约束。

### 心情子状态

- 心情叠加在六个 Core 主状态之上，不新增主状态，不改变健康判定。
- 每个心情必须有用户可察觉的原因，**不根据推断的情绪表演**：
  - `boring`：stable 下，用户离开 24 小时以上后回来；或发呆后继续安静 2 分钟。
  - `coolhide`：用户对当日型提示给出积极回答；或离开 3–24 小时后回来时 Pibo 躲进草丛（捉迷藏），点草丛找到它。
  - `dive`：用户回答“有点累／烦”这类选项后，Pibo 陪着潜一会儿。
- `bo` 成熟、收取和已有行为子状态（resting、greeted 等）优先于心情。
- `weak` 本期不启用。

### 首页草丛热点

首页新增一个草丛可点区域，用于捉迷藏与少量草丛台词，受注意力预算约束。

### 服务卡片

桌面服务卡片显示 Pibo 此刻在做什么的一句话（例如“躲在草丛里”），过期回落到常驻状态描述。卡片**永远不显示用户自定义文本**。

### 隐私

自定义文本只存本机：不写日志、不进埋点（埋点只记提示 ID、选项 ID 或 `custom`）、不同步服务端或 Shadow、不上卡片。设置重置与账号注销都会清除。

## 对既有决定的修订

- **修订决定 051**：拍一拍“不发展聊天机器人或大规模文案库”的边界放宽为：允许本决定定义的预设选项提示、单句自定义回复与回响，文案规模以首批约 10 个提示为上限，仍不做开放式对话。本功能进入 MVP，两周试用从本功能真机验收通过后重新计时。
- **修订决定 034 第 12 条**：本功能提供了用户输入渠道。Pibo 可以提出由用户在两个选项中选择或自行回复的问题，并在之后引用真实保存的回答；仍不得假装听见用户未提交的内容。
- **Core 版本**：决定 053 要求钉 `0.22.0`，HarmonyOS 实际钉在 `0.23.1`。本决定批准直接升至包含陪伴规则的 `0.24.0`；0.23 的变体选择合同保留在 Core 中但 App 不使用。

## 平台顺序

本决定 → `pibo-core 0.24.0` 发布陪伴预算、提示选择、记忆过期、回响资格与心情解析 → HarmonyOS 子模块、桥接、气泡与舞台实现 → HarmonyPibo `docs/harmony-first/2026-09-16-小生物陪伴提问与记忆回响.md` → iOS 精确 Swift Package 版本与表现补差。

提示、选项、回响和心情台词是数据目录，不进 Core；修改文案不需要发布 Core 标签。首批文案草案见 [companion-prompts-v1](../content/companion-prompts-v1.md)，经用户审核后才进入 App。
