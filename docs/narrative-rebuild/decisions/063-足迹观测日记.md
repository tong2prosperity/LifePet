# 决定 063：足迹是 Pibo 的观测日记

> 日期：2026-10-20
> 状态：已批准（2026-10-20，用户批准方案「足迹重做：从『健康记录』到『Pibo 的观测日记』」）
> 依据：用户 2026-10-20 提问——足迹的界面和逻辑是否也要重做、功能要不要增减；057 的「文字时间线保留为回看页」至今没有落地
> 范围：修订 051（足迹、睡眠「冻结云雾视觉」）与 057（足迹那一条）；iOS 不补齐（沿用 057）

## 1. 为什么

- 首页、读数报告、相机、设置都已经换成像素世界，只剩足迹还是白卡和圆角的「健康记录」。它的入口叫足迹，点进去却叫健康记录。
- Pibo 和你之间发生的事分散在好几个地方：时间线只在气泡里说一次，拍立得在成长页里，散步日记在收藏架里。057 承诺过的回看页一直没有。
- 045 规定原始数字属于睡眠回顾或足迹，所以足迹是数字合法的地方。但 051 也说过，不做报告中心。

## 2. 规则

1. **一天一页。** 页头写「地球第 N 天」和日期（N 是唯一的相处天数），可以前后翻页，不能翻到未来或相识之前。点日期打开像素月历：有记录的日子标一个小点，有「共同的第一次」的日子标一颗小星。月历不写数字，不评价好坏。
2. **上半页「Pibo 写的」**：只列当天真的发生过的事，包括读数结论、共同的第一次、讲到的小事、散步日记、地球食物样本、森林拍立得、季节来信。都没有时写一句安静的空白话。句子里不放数字，事实放在小字里。
3. **下半页「你的记录」**：睡眠、步数、活动、运动四张卡的图表照旧，外框换成像素。身体指标和 HRV 卡合并成一张「身体信号」，默认收起，展开后才显示数值。HRV 提醒点进来时直接展开到这里。
4. **足迹是唯一的回看处。** 拍立得画廊、散步日记都搬进足迹：成长页只留最新一张拍立得，收藏架只留收藏品，两处都留一个跳转到足迹的入口。森林里「共同的第一次」的标记，可以跳到发生的那一天。
5. **「记得的话」不列出来。** 陪伴回答仍只在本机，只由 Pibo 偶尔提起（沿用 054、056）。
6. **餐食只出现一次**，就是「Pibo 写的」里的样本；原来的餐食卡移走，样本可以点开餐食详情。

## 3. 不做

- 不做 7 天或 30 天趋势页，不加新指标，不加评分或连续天数。
- 不做医学判断，不改 055 的「你平时」说法。
- 不新增 Core 规则：结论读 Core 的分档，HRV 基线天数读 Core。

## 4. 与旧决定的关系

- 051：足迹和睡眠的「冻结云雾视觉」改为图表本身不变、只换外框；「真实、可读、日期一致、返回顺畅」照旧。
- 056、057：文字时间线的回看页，由足迹的「Pibo 写的」实现。
