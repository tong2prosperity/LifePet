# 决定 002：健康数据与产品规则

> 2026-09-05 按已确认产品方向精简。角色与养成定义统一见 [PRODUCT](../../PRODUCT.md)。

真实睡眠、步行和运动是养成输入，直接影响 Pibo 的可见状态，并形成用于永久能力的 `bo`。具体来源、计算、阈值、事件生命周期与回补规则由已发布 Core 统一负责。

- 健康事实由系统准确说明；角色可以回应和关心，不作医疗权威，不夸大单次行为的医学效果。
- 权限、数据是否可读、故事许可与首次设置完成分别建模，不因打开权限页就伪造健康事实。
- 长期未打开可读取的真实历史按合同回补；积累来自生活，不来自打开频率。故事显影有自己的节奏。
- 数据缺失不等于低健康或人格失败。负面状态及尚未确认的惩罚边界以 PRODUCT 为准。
- 固定故事骨架与少量分支继续作为创作素材；日常喂养、互动和成长先成立，完整主线不成为开发前置条件。
- 返航不自动触发，故事完成后健康功能、记忆和已购买资产仍有持续价值，详见决定 007/028。
