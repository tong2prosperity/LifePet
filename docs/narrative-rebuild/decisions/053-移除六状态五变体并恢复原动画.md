# 053：移除六状态五变体并恢复原动画

日期：2026-09-11。状态：用户已批准。批准原话：「移除30个状态变体，回退为之前的动画。」

## 决定

- 决定 052 批准的六状态各五段、共 30 段主状态表现退出 App，不再作为当前产品能力。
- 六个 Core 主状态 `dataUnknown / sleeping / waking / stable / energetic / tired` 不变；每个主状态恢复决定 052 接入前的既有单一主表现。
- `stableThinking`、`tiredResting`、`wakingRecovering`、`wakingGreeted` 等既有行为子状态，以及拍一拍、餐食观察、`bo` 成熟／收取和已有转场继续保留；本决定不是移除所有角色动画。
- App 不再选择、加载或展示 `-v0…v4` 资源，Debug 动画目录同步移除相应预览入口。`pibo_design/state-variants-v6/` 与 `pibo-media` 中的生成源可作为历史设计证据保留，但不得进入运行时或被描述为已发布能力。
- `pibo-core 0.23.0` 仅为这批变体增加的选择合同不再是 App 依赖；没有其他新合同要求时，HarmonyOS 恢复精确固定到变体接入前的 `0.22.0`。

## 平台顺序

HarmonyOS 先完成回退并验证。iOS 不应继续交付决定 052 的变体表现；若工作区已有未完成的变体接入，应在独立 iOS 补差轮次中撤回，不用 HarmonyOS 代码逐行覆盖 Swift／SpriteKit。

本决定替代决定 052 的当前发布方向，恢复决定 051 的单人陪伴 MVP 动画边界。实施和验证证据见 HarmonyPibo `docs/harmony-first/2026-09-11-移除六状态五变体并恢复原动画.md`。
