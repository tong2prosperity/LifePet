# 决定 018：故事事件生命周期

> 决定日期：2026-07-29  
> 状态：已拍板

## 事件状态

每个核心事件至少具有三个叙事状态：

1. **条件已满足**：健康能量与前置故事条件使事件可以发生，但主线尚未推进；
2. **进行中**：用户已经主动进入事件，但尚未完成最后一次必要互动；
3. **已完成**：用户完成事件，关系、使命或空间状态正式改变，主线才允许继续。

## 不自动打断

- 故事不会因为条件满足而自动播放；
- 故事提示不能弹窗强行打断健康功能；
- 用户忽略提示时，所有核心功能照常使用，当前阶段可以长期稳定停留；
- 用户必须主动触发，事件才从“条件已满足”进入“进行中”。

## 中途退出

- 用户可以中途退出事件，稍后继续；
- 中途退出不等于拒绝，也不造成失败、惩罚或 Pibo 受苦；
- 只有完成事件最后一次必要互动，事件才记为“已完成”。

## 事件后的变化

- 完成事件后，主页应在环境、物件、Pibo 行为、权限或关系状态中留下持续可见的变化；
- 该变化至少延续到后续阶段能够接住它，不要求永远保持同一视觉形态；
- 后来的环境与关系发展可以覆盖、改造或重新解释旧变化；
- 共同记录中的已完成事件永久保留，供用户回看。

## 标准流程

> 条件满足 → 主页出现非打断提示 → 用户主动触发 → 使用合适载体展开 → 完成最后互动 → 回到已变化的主页 → 写入共同记录
