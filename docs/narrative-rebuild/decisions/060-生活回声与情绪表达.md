# 决定 060：生活回声与情绪表达

> 日期：2026-10-20
> 状态：已批准（2026-10-20，用户选择「全部做」）
> 依据：用户 2026-10-20 要求——「更丰富的 Pibo 可以做的事情，与用户日常的运动、生活对应起来，更多的情绪表达，更多的动画」
> 范围：058 的一天之上；Core 规则与像素表现；iOS 不补齐（沿用 057）

## 1. 要解决的问题

058 里，Pibo 一天做什么只看它的六状态、时段、天气和装饰。用户的生活只通过六状态这一层间接传进来：
- 你去跑了步，Pibo 并不知道；
- 你吃了饭，Pibo 也不知道。

Pibo 的表情也只有几种眼睛，情绪多半靠台词撑。

## 2. 生活回声：你过的日子，Pibo 用自己的方式过一遍

Core 新增「生活事实」输入，平台只传事实，不传判断：
- 最近一次运动的类型、时长档、结束了多久；
- 今天的步数档、活动档；
- 昨晚的睡眠档、是不是很晚才睡；
- 最近一次餐食的类型和过了多久；
- 正念分钟。

Core 据此在一段时间里提高对应「回声活动」的权重。每种回声每天最多一次。

| 你的生活 | Pibo 的回声（新活动） | 窗口 |
| --- | --- | --- |
| 跑步 | **绕圈慢跑**：额头系一片叶子当头带，绕空地跑，跑完叉腰喘气 | 运动结束后 3 小时 |
| 骑行 | **空气单车**：坐在蘑菇凳上蹬空气，越蹬越快，最后自己晕了 | 同上 |
| 游泳 | **池塘狗刨**：在池塘或溪边浅水里扑腾；没有池塘就在草地上「旱泳」 | 同上 |
| 瑜伽 | **树式**：单脚站，摇摇晃晃，坚持住了会得意 | 同上 |
| 高强度 | **开合跳**：跳到一半忘了数到几 | 同上 |
| 步行 | **徒步**：背上小包、举着地图，在空地里认真「远行」 | 同上 |
| 运动之后 | **冷却**：摊坐着，用大叶子扇风，喝一口叶子杯里的水 | 紧接上面任一项 |
| 今天走了很多 | **量步子**：一步一步走，嘴里数，数乱了重来 | 当天步数档高 |
| 睡得很好 | **早操**：伸展 + 转圈，叶子特别挺 | 起床后上午 |
| 睡得少 | **哈欠连天**：走两步打一个哈欠，靠哪儿都想睡 | 当天 |
| 很晚还醒着 | **守夜**：戴睡帽、提一盏小灯，假装巡逻，其实在打瞌睡 | 23:30 以后打开 |
| 刚吃过饭 | **野餐**：坐着吃一颗浆果，吃完拍肚子 | 餐食识别成功后 90 分钟 |
| 饭点（无记录也有） | **烤蘑菇**：有篝火时在火边烤，没有时就闻一闻 | 早／午／晚饭时段 |
| 做了正念 | **打坐**：闭眼，身体随呼吸一胀一缩 | 正念记录后 2 小时 |

**边界**（034／057 的文案 lint 继续生效）：
- 回声只对「做了的事」发生。不对「没做」「做得少」做任何反应——不催促、不制造愧疚；
- 「睡得少」只让 Pibo 自己困，不评价你；
- 不出现数字，不做医学判断；
- 回声台词带一行事实小字，只写定性内容（例如「你今天去跑步了」）。

## 3. 情绪表达

Core 新增「情绪」选择：情境给出一个情绪，平台负责画。

新增十种情绪。每种有专属的眼睛、嘴、身体动作和头顶符号：

| 情绪 | 表现 | 常见情境 |
| --- | --- | --- |
| 惊讶 | 圆眼、身体一缩一弹、「!」 | 被找到、天气突变、你很久没来 |
| 害羞 | 眯眼、脸红加深、扭一下 | 连续被拍 |
| 得意 | 闭眼微笑、叉腰挺胸、闪光 | 树式坚持住、找到稀有发现物 |
| 困惑 | 一大一小眼、歪头、「?」 | 被邀请去做它刚做完的事 |
| 小委屈 | 嘴角下撇、背过身半拍 | 拒绝它的邀请后马上又拍它（一会儿就好） |
| 无聊 | 半睁眼、晃脚、「…」 | 长时间没有互动 |
| 感动 | 星星眼、眼角闪一下 | 收到来信、第一片叶子 |
| 打喷嚏 | 蓄力 → 喷 → 晃 | 闻花、下雪 |
| 发抖 | 小幅左右抖、呼白气 | 冬天夜里、下雪 |
| 热 | 吐舌、扇风、汗滴 | 夏天正午、运动之后 |

另外补一组随机的**小动作**，在闲着时偶尔播放：
- 眨眼变体；
- 四处张望；
- 挠头；
- 打哈欠；
- 绊一下又站稳；
- 打嗝。

## 4. 规则归属

- 回声的事实档位、窗口、权重、每日一次，以及情绪的情境映射，全部进 `pibo-core` 0.31.0（`day.rs` 扩展，新增 `emote.rs`）；
- 平台只负责：
  - 采集事实（华为健康、餐食记录）；
  - 画姿势、道具、表情、符号；
  - 台词。

## 5. 与其他决定的关系

- 不改 055：运动回应仍然留在森林里，回声是它之后的延续；
- 不改 057 的经验与 `bo` 数值，回声不发奖励；
- 不改 054／056 的陪伴预算：
  - 回声台词走 058 的一天台词；
  - 只在 Pibo 被看到时说，每种每天一次。
