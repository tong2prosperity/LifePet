# 决定 032：共同物件与能力

> 2026-09-05 清除被 043/046 替代的旧门控及修订正文。

共同物件是永久行为与能力，不只是装饰。完整目录、成本和表现见[决定 046](046-共同物件渐进解锁、能力与发现反馈.md)，好友合同见[决定 043](043-Shadow-Pibo双向单好友映照系统.md)。

- 森林显示已拥有物件与唯一的下一个灰态目标；点击目标打开 Half Sheet，说明能力、成本、可用量与不足原因。
- 成熟 bo 保持在头顶，用户确认后由 Core 原子直接投入；关闭检视不扣除，不出现独立拔取、背包或解锁结果页。
- 获得物件后在同一森林中发现持续能力，下一目标再显现。
- 吊床提供睡眠回顾与睡醒行为；观测仪提供个人准备度与趋势；风铃提供散步回声收藏与重播；铃兰灯提供逐盏点灯与共光态。
- 健康授权、原始健康记录、bo 形成、基础餐食相机、散步涂鸦与 Shadow 基础关系不受这些物件门控。
- 顺序、成本、前置、永久所有权及派生能力由 Core 定义；旧用户所有权与消费幂等继续保留。
