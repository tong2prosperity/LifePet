# 决定 037：Pibo 小说参考文风强度

> 决定日期：2026-08-19
>
> 状态：已冻结
>
> 适用范围：Pibo 小说的大纲、场景卡、正文生成、续写与修订

## 决定内容

Pibo 小说不只借鉴《超魔杀帝国》的宏观结构，也必须明显借鉴文风圣经中已经抽象出的整体
阅读机制：第一人称近距离即时反应、高对白密度、中短句与短段落形成的速度、人物化幽默
作为高压冒险的减压阀、设定解释嵌入危险与争论、关系通过言行反差显露，以及文风从开篇
轻快冒险逐步转向中后段沉重结算。

这里的“明显借鉴”指读者能够感受到相近的叙事速度、人物互动强度、轻重交替和章节牵引，
而不是只在幕后使用相同的大纲方法。仍不复制参考作品的具体句子、比喻、口头禅、网络梗、
人物、设定、情节或可识别语言指纹。

## 全书语言基准

- 刘林克第一人称长期贴近当下感受、判断和误判；
- 以中短句、短段落、高换行和高对白密度作为正文常态；
- 常用节奏为“中短句 → 对白 → 即时判断 → 中句解释”；
- 单句成段优先用于笑点、突然发现、危险判断和情绪落点；
- 动作场景保持快读，但规则、能力或局势发生关键变化时允许主动放慢解释；
- 环境描写服务于定位、危险、感官和人物注意力，不持续铺陈；
- 世界观通过利益冲突、行动失败、证据和争论进入正文，不使用百科式讲解；
- 一个局部答案通常修改旧判断，并打开更大的问题；
- 重要关系依靠对白态度与实际行动之间的反差建立。

## 对白与幽默

全书采用高对白密度。对白同时承担人物区分、信息传递、关系竞争和节奏调节，不只是把已经
发生的事情说出来。

幽默是结构部件，不是可有可无的装饰。开篇和组队阶段可以保持较高强度；随着世界危机、
背叛和关系裂缝加深，幽默逐步减少，但人物原有语言习惯不能突然消失。不可逆死亡、告别、
背叛确认和重大牺牲的情绪中心不插入笑点，幽默主要出现在高潮之前、之后或行动间隙。

Pibo 本人的说话方式继续遵守决定 005 与 034，不改成高频吐槽者。全书的对白活力和喜剧
主要由刘林克的即时判断、其他角色的语言差异、语域错位、误解、争论和群像关系承担；Pibo
以认真、直接、程序化的回应产生反差幽默。

## 动态文风

### 开篇与早期冒险

- 速度快、对白多、误解多；
- 刘林克的自我辩解和即时判断更活跃；
- 新人物和局部异常不断打开世界；
- 危险与喜剧交替，保持强可读性。

### 组队与世界扩张

- 对白和冒险仍占主导；
- 设定解释与阵营争论增多；
- 危险从单纯追逐升级为多项规则同时限制选择；
- 人物秘密开始修改彼此关系。

### 真相裂缝

- 对白可以变长，语言与行动的矛盾增强；
- 幽默减少但不断绝；
- 叙事重心从“发生了什么”转向“谁早已知道、为何不说、现在还能否相信”；
- 旧日轻松场景和物件获得新的痛感。

### 高潮与结尾

- 战斗、世界真相、身份和关系同步结算；
- 停止扩张无关新人物，集中回收旧伏笔；
- 世界尺度最大时，情绪落点反而回到私人动作、等待和普通话语；
- 高潮后的静场必须保留，不用连续爆点吞掉告别重量。

## 写作模型执行要求

交给正文模型的 Prompt 必须同时包含：本决定、`novel/01-参考叙事技法适配.md`、当前场景卡、
人物语言卡和连续性账本。正文验收至少检查对白比例、段落速度、即时判断、幽默位置、设定
进入方式、章节局部答案与新问题，以及角色说话是否可区分。

不得只写“参考《超魔杀帝国》的文风”。必须提供上述可执行参数，避免模型把借鉴误解为
复制表面口癖或网络语言。
