# 056：Pibo 的时间线（文字版）

日期：2026-09-28。状态：用户已批准方向（「实现，先实现鸿蒙端」），HarmonyOS 先行，iOS 按 Harmony-first 记录补差。批准依据：用户确认「MVP 放行文字版的 Pibo 时间线，画面上的痕迹以后再做」「名字这次不做，`mowanGreeting` 直接删掉」。首批文案由实现方按决定 034 起草，随数据目录可审可改。

## 背景

- 陪伴提问（决定 054）让 Pibo 会问、会记住；但一个回答最多换来一句当场反应和一次回响，之后没有任何地方再用到它。
- 台词里的石头收藏、来做客的甲虫只是写死的句子，第二天不会延续。Pibo 所有会持续下去的东西都和健康数据绑定，它仍像一面镜子，没有自己的生活。
- 两套「相处天数」各算各的：足迹的「陪你走过的第 N 天」从相识当天算第 1 天；陪伴层级从陪伴功能首次加载算起、从 0 开始，同一个人会得到两种天数，层级也晚一天解锁。
- 按天数叫名字的问候（`mowanGreeting`）是 8 月撤下的旧规格遗留，从未显示，句子池里还有「该出门了」「加油」这类督促句（决定 034 禁用）。

## 决定

### 一套相处天数

「相处第 N 天」只有一个定义：Pibo 和这个人相识的那个本地日是第 1 天，设置里「重新开始」时归零。足迹、陪伴层级和时间线都读它。决定 054 里的「第 4 天起」「相处 ≥5 天」按这个天数计算。

### 回答变成 Pibo 记住的事

- 新增「记得的话」：挂在真实时刻（槽位与条件）上，只在对应回答仍在记忆里时出现。例：下雨时，如果你说过喜欢下雨——「下雨了。我记得你说过，你喜欢这种天。」
- 条件标记新增 `requiresAnswer`（需要某条回答）与 `excludesAnswer`（某条回答存在时不出现），写法为 `提示ID:选项ID` 或 `提示ID`，用于提问与记得的话。自定义回复从不作条件，只在回响里原话引用。
- 每条记得的话有自己的冷却（至少 1 天），计入每日主动句；回答按决定 054 的期限过期（当日／近期 3 天／偏好 180 天）后，它就不再出现。不引用数字，不评价人。

### Pibo 自己的小事

- MVP 有两件：「石头收藏」与「来做客的甲虫」，各 7 步。石头在第 1、3、5…13 天，甲虫在第 2、4…14 天，每天最多讲一步，两周讲完。
- 一步只讲一次，在它的日子或之后第一个合适的时机：拍一拍说完之后、刚醒、离开后回来。错过的步子不丢，按顺序接着讲；日子已过或在你回来时讲的，用「你不在的时候……」的说法。不抱怨，不记账，缺席不少讲。
- 做什么与健康数据无关；怎么做跟随当下状态：精神好时爬高去找，累了就坐着把石头排好。
- 本功能上线前就开始的关系，小事从上线那天算第 1 步，不假装以前讲过。

### 共同的第一次

- 只记能核实的第一次：第一次拍一拍、第一次收 `bo`、第一次看它睡在吊床上、第一次给它看餐食，记本地时间。上线前就开始的关系，无法确认先前是否发生过的项目不记录，不编造；餐食可以从已保存的记录里核实最早一次。
- 相处第 7 天与第 14 天（当天或之后第一个合适的时机），Pibo 提起一件：按「收 `bo` → 餐食 → 吊床 → 拍一拍」挑还没提过的，例如「第一枚 bo，是认识的第二天傍晚，你帮我收的。」一件只提一次；什么都没记下就不说。

### 顺序与额度

- 全部走决定 054 的注意力预算：每次进入首页 1 句、每天 3 句主动句、与拍一拍共用 3 秒冷却，不因此更吵。睡着时不说。
- 同一个时机依次尝试：回响 → 共同的第一次 → 自己的小事 → 记得的话 → 提问 → 场景句。
- 不做连续天数、奖励和让人愧疚的东西（决定 043、046）。时间线只存手机本地，不上传、不进埋点正文、不上服务卡片，随设置重置与注销清除。
- 以上挑选规则由 Core 决定；文案是数据目录。

### 删除 mowanGreeting

删除从未显示的按天数叫名字的问候及其句子池。本轮不做名字。

## 对既有决定的修订

- **修订决定 051**：MVP 放行本决定的文字版时间线，不加美术。森林里能看见的痕迹（例如木头下面的石头慢慢变多）留到 MVP 之后另行决定。
- **修订决定 054（与已上线实现对齐）**：
  - 每天提问：前 3 天 1 个，第 4 天起且最近回答率 ≥50% 时 2 个；
  - 记忆期限：当日、近期 3 天、偏好 180 天；
  - 文案规模：首批 38 个提示；原「约 10 个」上限放宽为当前目录加本决定的时间线文案；
  - 把 Pibo 送下水的回答（「有点累」「去踩水」）在安稳、疲倦、活跃时都会下水；回响不在回答所在的那次首页访问出现（均自 `pibo-core 0.26.0`）。
