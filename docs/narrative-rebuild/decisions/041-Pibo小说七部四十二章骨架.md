# 决定 041：Pibo 小说七部四十二章骨架

> 决定日期：2026-08-19
>
> 状态：全书骨架仍有效；情感层章节落点已由决定 042 扩展
>
> 适用范围：Pibo 小说工作线

## 决定内容

小说采用七部四十二章、预计 22–26 万字和 90–105 个场景。七部继续对应原有七个关系阶段，
每部六章；二十一个核心事件平均跨越两章，并嵌入九十日归潮、四方阵营和外部冒险行动，
不再作为孤立产品事件。

七部依次为：

1. **错误连接**：软件异常升级为真实接触，第一枚 `bo` 同时暴露航迹；
2. **城市里的回声**：稳定交换、城市追踪、用途分歧与第一次现实逃亡；
3. **门后的森林**：首次物理跨越、萨因回收、灰航袭击、雾祈重逢与无用记录选择；
4. **故乡显影**：故乡信号、候选世界、消失森林和 Pibo 私下恢复任务；
5. **任务页**：Pibo、林见夏、沈簇、涅芙与索弥的不同隐瞒集中清算，关系知情重建；
6. **第三条路**：旧取火伤害、弥洛与科岚的配给旧伤、原生 `bo`、有限试验和四方联盟；
7. **归潮**：多方密钥争夺、第三条路执行、私人关系结算、Pibo 自主返航与延迟记录。

## 结构要求

- 第一至三部保持高对白、高幽默、快速人物进入和局部冒险扩张；
- 第四部增加世界信息，但解释必须绑定潜入、规则空间、追踪和谈判；
- 第五部集中关系与真相裂缝，每次揭露必须改变联盟、资源和行动；
- 第六部把伦理异议转换成能失败、可回退的实际方案；
- 第七部高潮前不再新增核心世界规则，第 40—42 章显著降速完成私人告别；
- 正文仍采用刘林克第一人称限知，知识揭露遵守 `novel/05-人物弧与知识状态.md`；
- 章名为工作标题，逐章卡可以调整标题和场景切分，不能改变核心因果与不可逆转折。

## 规模修正

本决定正式替代决定 035 中已经重新打开的 12–15 万字、28–32 章和 55–65 场景建议。新增
群像、四方阵营、地球行动线、故乡行动线和九十日归潮需要更大的叙事容量。
