# 决定 021：第一阶段“错误连接”事件基础

## 事件 01：错误抵达

Pibo 与用户相遇前已经观察过地球并选择制造森林季。初见时它正在主动校准广播连接，不以受伤、可怜或等待拯救的姿态出现。用户主动回应后故事开始；暂不回应仍可使用核心工具。

## 事件 02：临时约定

双方建立清楚、可撤回的临时合作。Pibo 表达请求，系统权限页准确说明授权。至少获得一种可产生健康能量的数据来源后事件才完成；拒绝时故事暂停，不产生负面反馈。

## 事件 03：第一枚 `bo`

第一枚 `bo` 由日常健康数据自然积累，不要求指定任务。成熟后不会过期或伤害 Pibo；用户主动拔下后进入由用户控制的库存，不自动用于返航。

## 阶段结果

双方从偶然互相看见，经过知情授权，进入以 `bo` 为共同事实的临时合作；尚未建立友情，也没有照料关系。
