# 决定 011：Pibo 故事基础阶段结论

> 决定日期：2026-07-27  
> 状态：阶段完成

## 阶段结论

Pibo 新叙事的故事基础已经具备进入主线事件大纲的条件。

已经闭合的因果链是：

> 漫长环境异常迫使故乡进入封闭生存系统 → 数代合理选择形成路径依赖 → 故乡自身 `bo` 产量下降 → 文明误判为外部能源不足并启动取火计划 → 年轻 Pibo 首次独立远行 → 航行事故造成情景记忆损伤 → 用户健康行为产生的 `bo` 帮助它恢复 → 共同经历使 Pibo 发现身体、能量和关系不能只按用途衡量 → Pibo 与用户完成同行并主动告别 → Pibo 返回故乡，与引路者开始有限修复试验。

## 已确定的故事基础

- 核心命题：身体不是维持运转和完成目标的工具，而是生命参与世界与关系的所在；
- 科幻定位：外星文明的未来史映照人类可能面对的技术路径，但不是简单反 AI 寓言；
- 世界历史：漫长避难、封闭系统、代际路径依赖和取火计划；
- Pibo：第一次独立远行、认真直接、努力可靠的年轻取火者；
- 用户：没有预写身世，通过真实行为与关键选择参与关系；
- 引路者：长期关心 Pibo 的职业导师，也是旧方案最有善意和经验的承担者；
- `bo`：由健康行为估算生长的实体科幻能源，可消费、可返航、可以继续积累；
- App：观察、沟通与翻译窗口，不是 Pibo 的数字容器；
- 主线：错误连接、互相利用、无用记录、故乡显影、真相裂缝、共同改写使命、从容告别；
- 终局：主线完成、返航库存足够、双方明确选择后离开，不自动结算；
- 气质：轻松、愉快、坦然、从容，沉重而不卖惨。
