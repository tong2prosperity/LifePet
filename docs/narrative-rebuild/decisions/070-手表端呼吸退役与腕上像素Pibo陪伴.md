# 决定 070：手表端呼吸退役与腕上像素 Pibo 陪伴

> 日期：2026-10-23
> 状态：已批准（2026-10-23，用户原话：「我感觉不需要呼吸的这个功能了吧，之前做呼吸就是不知道要干什么才做的，现在来看还有必要么？你提出的腕上像素pibo陪伴是一个非常好的思路。」「写一份新的决定然后开始改造实现，注意这是华为的鸿蒙手机app，注意它的特性，然后开始实现」）
> 范围：修订 069 中「独立手表呼吸应用不变」条款；退役鸿蒙穿戴端呼吸训练，改为与鸿蒙手机像素主线一致的「腕上像素 Pibo 陪伴」；结合华为鸿蒙（HarmonyOS NEXT API 20）多端协同与本地健康特性实现；iOS 不补齐（沿用 057）

## 1. 背景与为什么退役「呼吸」

- 9 月初立项 `pibo-呼吸` 时，手机端尚未完成像素化重构（057–065），没有「Pibo 的一天」「生活回声与变形」「走路出门探险」和「今日小心愿」，手表端因缺乏核心陪伴内容才以呼吸计时器作为替补。
- 华为手表系统出厂自带「呼吸训练／减压」应用，第三方呼吸计时器与系统能力高度同质化，且背负了实时心率流订阅、加速度计贴胸腹姿势估算、音频路由打断与后台代理提醒等沉重包袱。
- 像素版主线成型后，Pibo 的核心魅力是**「一只由你的真实生活喂养、看得见地长大、会变形、会出门探险的像素小生命」**。手腕恰恰是用户走路、运动、作息的发生地，也是「抬腕 2 秒一瞥」的最佳窗口。

## 2. 结合华为鸿蒙（HarmonyOS）特性的架构设计

本项目是华为鸿蒙应用（`HarmonyPibo`，API 20 Stage 模型），由手机主端 `entry/` 与穿戴端 `wearable/` 组成。设计必须贴合华为鸿蒙生态的真实特性：

1. **华为运动健康（`@kit.HealthServiceKit`）与穿戴引擎（`@kit.WearEngine`）双通道协同**：
   - **连机快照（Wear Engine P2P）**：当配对的华为智能表与鸿蒙手机连接时，手机端通过 `WearableCompanionSnapshot`（v2，向下兼容 v1）将 Core 已判定的 Pibo 状态、成长等级、外观配饰（体型、头顶 `bo` 叶、围巾、橡果帽、小背包、夜光叶）、胸口读数徽章、`bo` 进度与成熟态、当前变形形态（`PiboForm`）、今日 3 个小心愿盖章状态及出门探险收获同步至手表。
   - **独立运行与离线降级（HealthServiceKit + 本地存储）**：鸿蒙穿戴应用支持脱离手机独立运行，且模拟器或部分设备不包含 Wear Engine HSP。穿戴端必须通过 `canIUse('SystemCapability.Health.WearEngine')` 与动态 `import()` 门控加载；当手机未连接或不可达时，手表直接通过 `@kit.HealthServiceKit` 按需读取本地当日 `DAILY_ACTIVITIES`（步数／热量／活动）、`SLEEP_RECORD`（睡眠）与 `WORKOUT`（跑步／骑行／游泳／瑜伽／步行），驱动像素 Pibo 的本地运动变形、走路探险进度与状态展示。
   - **严守 Core 边界与真实数据铁律**：手表端不复制 `pibo-core` 的六状态睡眠／HRV／压力阈值；无手机快照时仅映射本地已观测到的真实运动／睡眠／步数事实，无授权或无数据时温和展示中性状态或空态，严禁伪造／Mock 生理数据。
2. **鸿蒙穿戴端圆形表盘（466×466）、手势与硬件规范**：
   - **OLED 纯黑省电舞台**：窗口固定 `#000000` 全屏背景（`setWindowLayoutFullScreen(true)`），遵守 `AvoidAreaType.TYPE_SYSTEM`、`TYPE_CUTOUT`、`TYPE_NAVIGATION_INDICATOR` 顶底弧形安全边距（`topInsetPx`／`bottomInsetPx`），避免圆表边缘裁切。
   - **系统右滑返回与原生表冠滚动**：鸿蒙穿戴系统全局手势为右滑返回；页面采用纵向 `Scroll` 两屏结构并显式获焦（`focusable(true)`、`defaultFocus(true)`），原生支持旋转华为手表表冠上下顺滑切换「首屏：像素 Pibo 小剧场」与「次屏：今日一瞥」，不劫持系统表冠按压或右滑返回。
   - **前台按需步进渲染**：穿戴端通过姊妹像素渲染层（`PixelFrame` + `CanvasRenderingContext2D`，`imageSmoothingEnabled = false` 最近邻整数倍放大）按 10fps（100ms）步进绘制；开启「减弱动态」或退入后台（`onPageHide`）／息屏时立即停止定时器，保持零后台耗电。
   - **权限精简**：移除已退役呼吸训练专用的 `ohos.permission.ACCELEROMETER`、`ohos.permission.PUBLISH_AGENT_REMINDER` 及呼吸静态快捷方式；仅保留轻触觉 `ohos.permission.VIBRATE` 与按需授权的 `ohos.permission.READ_HEALTH_DATA`。

## 3. 手表端展示内容（一主屏 + 一次屏）

### 3.1 首屏：腕上像素 Pibo 小剧场（抬腕 2 秒即见）

1. **像素 Pibo 与微缩苔藓林地**：
   - 圆形表盘中央展示与手机端同源的程序式像素 Pibo（无黑边白麻薯、点点眼、双瓣鼻吻、头顶锯齿 `bo` 叶、已解锁围巾／橡果帽／背包／夜光叶与胸口读数徽章），脚下为随昼／昏／夜／雨换色的微缩像素苔藓草地（夜间带闪烁像素星光与萤火虫）。
2. **实时状态与生活回声变形（060／061）**：
   - 日常展示六状态动作（睡觉冒泡 `zZ`、早起伸懒腰、活力蹦跳、疲惫打盹、问号等待连接）；
   - 当存在真实运动或作息回声时，直接在表盘中央展示像素变形或回声动作：
     - 跑步／高步数 → **像素跑鞋**蹦跳；
     - 骑行 → **像素小自行车**；
     - 游泳 → **像素小鱼**吐泡泡；
     - 瑜伽 → **像素小树苗**；
     - 高强度运动 → **像素弹簧**；
     - 睡得好 → **像素枕头／早操**；
     - 深夜未睡（23:30 后） → **像素小夜灯**；
     - 刚吃过饭 → **像素小饭碗**；
     - 打喷嚏漏出 → **像素石头或蘑菇**（几秒后弹回）。
3. **顶部状态与头顶 `bo` 胶囊**：
   - 顶部安全区内展示 Pibo 名称／等级与 `[🍃 bo X]` 胶囊；
   - 头顶 `bo` 叶按生长进度（嫩芽 → 长叶 → 双叶 → 花苞 → 成熟金光）绘制；成熟时胶囊切换为暖金高亮并浮现 `▲ 上拉收取` 提示。
4. **底部弧区：「你走路，Pibo 也出门」探险路标（058 第 6 节）**：
   - 根据当日真实步数对照 `2000（草坡）／5000（松林）／8000（河边）／12000（山顶）` 探险节点，底部显示当前探险目的地与进度；跨过节点时 Pibo 抱回一件像素发现物（松果、羽毛、四叶草、小晶石等）等你点收。

### 3.2 下滑次屏：今日一瞥（旋转表冠或上滑查看）

1. **今日小心愿盖章栏**：展示今日 3 个小心愿的像素图标、简短名称与完成盖章状态 `[✓]`；
2. **今日探险收获架**：展示今天走路已带回的发现物像素图标与简短散步日记；
3. **今日活动与健康连接**：展示已读到的真实步数／活动消耗／锻炼时长事实（无数据时显示 `--`，未授权时提供一键连接华为运动健康入口）及「触感反馈」「减弱动态」两个极简开关。

## 4. 腕上 3 秒轻交互功能

1. **双击 Pibo「拍一拍」与「解救卡住变形」**：
   - 在像素 Pibo 上双击，触发 `@ohos.vibrator` 轻触觉（自动检测高级预置触感或降级为短脉冲）、播放 10 种像素情绪反应（惊讶 `!`、害羞 `♥`、得意闪光、打喷嚏漏出石头形态等）并浮现一句简短像素气泡台词（遵守 034／057／059 文案边界，不催促、不写数字）；
   - 当 Pibo 处于变形「卡住变不回去（stuck）」扭动冒汗状态时，双击它即刻「噗」地弹回白麻薯形态并道谢。
2. **头顶成熟 `bo` 上拉收取（048）**：
   - 当头顶 `bo` 成熟发金光时，在表盘中央向上轻滑（或点击成熟胶囊），触发两段拉伸动画与阶梯触觉反馈，释放能量收进常驻 `bo` 余额，头顶容器不脱落。
3. **轻点挠头叶与收起探险发现物**：
   - 单击 Pibo 触发轻柔眨眼与头叶晃动；当 Pibo 抱回新的探险发现物时，点击即可收进今日收获架并获得欢呼反馈。

## 5. 不做

- 彻底移除呼吸节奏计时、呼吸频率／时长设置、心率流与腕动呼吸传感器采集、呼吸音频与每日呼吸代理提醒；
- 不在手表端放置装饰商店购买、长篇第一／二季剧情阅读、餐食拍照或打字输入；
- 不新增货币、不计连续打卡天数、不发催促通知；
- 不修改手机端 `tools/fixtures/pixel-visual-baseline.json` 保护的 26 个像素绘制源文件。
