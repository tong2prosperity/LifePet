# 故事与 IP 评估（提案）

> 日期：2026-10-20
> 状态：待用户确认；本文件是评估与建议，不是决定。确认的部分再写成新决定（059 起）。
> 范围：决定 003–011、013–021、035–042，`16-二十一个主线事件-v0.3.md`，`novel/`，以及它们与像素版（057、058）的关系。

## 1. 结论先说

故事的**根**是好的，值得保留并做成独立 IP：

> 一个为了活下去而把生活改成「维持运转」的远方文明，`bo` 越来越少；年轻的 Pibo 来到地球，发现 `bo` 是从好好睡觉、走路、晒太阳这种普通生活里长出来的。

这条设定把「真实健康数据」和「异世界生命」焊在了一起，是别的宠物 App 没有的东西。没有反派、只有路径依赖的故乡也很有质感。

但现在的故事**还不是一个 IP，而是三套互相打架的方案**，而且主线的结构是为「关系剧」设计的，和像素版的「每天去看它过日子」不合拍。需要推翻的部分比需要新写的部分多。

## 2. 主要问题

### 2.1 没有唯一正史

| 版本 | 时间跨度 | 角色 | 森林是什么 | 结局 |
| --- | --- | --- | --- | --- |
| App 主线（003–021、16） | 一年、七阶段、二十一事件 | 用户、Pibo、引路者 | Pibo 在自己空间做出的「森林季」 | Pibo 返航、告别 |
| 小说（035–042、`novel/`） | 九十日归潮倒计时 | 十一人、四方阵营，程序员刘林克第一人称 | 取火舱里真实的种生境，卡在「薄层」 | 第三条路、返航 |
| 像素版（057） | 无 | Pibo + 森林小生物 | 三个场景，可以旅行和探险 | 无，只留「异世界来客」一句 |

IP 需要一个与媒介无关的正史：Pibo 是谁、从哪来、森林是什么、它在地球做什么。App、小说、周边都是这个正史的不同讲法。现在每个媒介各自重新发明了一遍。

### 2.2 主线的终点是「Pibo 离开」

App 主线的终局是返航告别，之后 App 变成「低频远程连接」。对一只要陪用户很久的电子宠物来说，这等于把产品的终点写成「宠物走了」。

这和持续运营、装饰目录、等级成长都冲突。主线里虽然写了「不倒计时、不自动离开」，但一个以告别为目标的故事，越往后讲，用户越清楚在走向失去。

### 2.3 戏剧冲突建立在「用户被利用和被欺骗」上

第二阶段「互相利用」、第五阶段「真相裂缝」：用户发现自己是取火计划的验证对象，Pibo 恢复记忆后故意隐瞒，用户要决定是否继续。

这在小说里是好戏，放在 App 里却是让用户和自己养的宠物之间出现背叛。「用户 = `bo` 来源 / 矿井」这层框架，即使反复声明无害，也在暗示「你的健康被拿走了」。这和 PRODUCT「喂养可见、陪伴有回应」的温暖基调相反。

### 2.4 失忆已被否掉，主线却还靠它驱动

决定 049 撤掉了首启的失忆、乱码和临时合作，但主线前四个阶段的推进器仍是「记忆恢复 → 故乡显影」。驱动器拆了，后面的阶段就没有起点。失忆本身也是最常见的套路，没有给 Pibo 增加特色。

### 2.5 故事的锚点物件已经不存在了

- 主线的核心关系物件是风铃灯（013、014），057 已经把风铃和铃兰灯移出路线图；
- 睡眠窝、悬挂的灯、共享任务页、物件检视里投入 `bo`，在像素版里也都没有了。

故事的「看得见的部分」几乎全落在被删掉的东西上。

### 2.6 好看的素材太少，抽象的东西太多

主线主要靠记忆碎片、档案、对白和「理解」推进，核心主题是「身体不只按用途衡量」。这在小说里能撑住，在像素首页里几乎没有可以「看」的东西。

像素版现在真正有生命力的是：
- 森林里的小生物（松鼠、甲虫、鱼、蝴蝶）；
- 地点；
- 天气、季节；
- 出门探险带回来的东西；
- Pibo 每天自己找事做。

故事完全没有用到这些。宠物 IP 通常靠「配角群 + 地点 + 反复出现的小情境」长大，而不是靠一条单线主线。

### 2.7 Pibo 的人设已经漂移

- 005 / 034：认真、程序化、职业取火者，不吐槽、不傲娇；
- 057 实现：麻薯形、会犯傻、有分档吐槽（「我从这头滚到那头也差不多」），老朋友档互损。

这不一定是错，但需要明确哪个是正版。我的判断是：像素版的 Pibo 更可爱，也更好玩，应该以它为准，同时保留「认真、好奇、直接」作为底色。也就是说，它是一个认真得有点好笑的家伙，而不是一个职业程序。

### 2.8 小说和 App 的气质不在一个频道

小说是近未来、安全机构、四方阵营、追捕、九十日倒计时、「净航可能杀死舱内生命」，这是一部紧张的科幻冒险。它可以作为 IP 的一个延伸作品，但不能直接塞进首页。

第一章的叙述声音是这批材料里最有趣、最成熟的文字，值得保留。

### 2.9 过程成本远大于交付

- 二十一个事件、四十二章骨架、十一个人物，App 里一个都没上线；
- 事件 01–03 暂停；
- 原本的六屏故事引导关在开关后面。

继续按这套规模推进，很难在像素版里落地。

## 3. 建议推翻的设定

| 设定 | 建议 | 理由 |
| --- | --- | --- |
| 返航告别是主线终局 | **推翻**。改为开放连载，「回故乡」变成可重复的远行或通信，而不是离开 | 宠物不该以离开为终点；与持续运营冲突 |
| 失忆驱动主线 | **推翻**。Pibo 知道自己是谁，只是不明白一件事：为什么故乡长不出 `bo`，而地球可以 | 049 已否；套路化；改成好奇心驱动更符合人设 |
| 用户是能源来源和验证对象，Pibo 隐瞒任务 | **App 中推翻**；小说可保留为另一条线 | 背叛感伤害养宠关系；「健康被拿走」的暗示 |
| 「取火」意味着从地球收集 `bo` | **改写**。`bo` 不会从你身上被拿走，它长在 Pibo 头顶，是你们一起生活的结果；Pibo 来地球是学「怎么长出 `bo`」 | 去掉采集伦理问题，保留主题 |
| 风铃灯是核心关系物件 | **推翻**，换成像素版里实际存在的东西（见 4.3） | 物件已被移除 |
| 三人阵容限制（009） | **放开**，但新角色主要是森林里的小生物和远方的通信者，不是阵营 | 宠物 IP 靠配角群；阵营留给小说 |
| 「认真、程序化、不吐槽」的说话标尺（034 部分） | **修订**为：认真、好奇、直接，偶尔认真得好笑；吐槽按熟悉度分档（已在 057 实现） | 与实际实现对齐 |
| 小说九十日归潮、穹镜、净航 | **降为小说专属**，不进 App 正史 | 气质与 App 不同；可作延伸作品 |

## 4. 建议保留并加强的设定

1. **故乡**：漫长避难、封闭栖居系统、每一代都做了合理的选择、最后生活被压成「维持运转」，`bo` 越来越少。没有反派。（004、008）
2. **`bo` 的本质**：生命好好生活时自然长出来的东西。头顶的 `bo` 就是 Pibo 在地球学到的证据。（003 改写后）
3. **Pibo 的底色**：年轻、第一次独自出远门、认真、好奇、直接、有自尊；想把事情做好，常常做得有点好笑。（005 修订）
4. **引路者**：故乡里一直等它的那位。不出场，只通过远方来信出现，是故乡最具体的面孔。（010）
5. **偶然相遇，App 是窗口**：用户不是被选中的。关系的特别来自一起度过的时间。（006）
6. **用户留白**：不给用户编身世。（009）

### 4.1 建议的一页正史（待确认）

> Pibo 来自很远的一颗星球。那里的人为了躲过一场很长的灾难，搬进了处处被照顾好的穹顶，几代人以后，大家都不太会自己睡觉、走路、晒太阳了，能让生命发光的 `bo` 越来越少。
>
> 年轻的 Pibo 自告奋勇出来找答案，带着一粒种子和一个小舱，落在了地球的一片森林边上。它发现地球上的生命不用任何机器，只是好好过日子，`bo` 就会自己长出来——而当它跟着一个人类一起生活时，它自己头顶也开始长了。
>
> 于是它决定先不走：把森林住明白，把这里的事一件件记下来，寄回去。

这个版本：
- 保留了故乡与主题；
- 没有失忆、欺骗和告别；
- 解释了头顶的 `bo`、森林、出门探险，以及为什么 Pibo 会看星星（在看家的方向）；
- 用户的健康是「一起生活」而不是「被采集」。

## 5. 如何融入像素版

原则：故事不挡任何日常功能；每天最多一个故事节拍，走 Core 的注意力预算；所有触发条件进 `pibo-core`。

### 5.1 结构：季，不是一条长主线

- 一「季」约 2–3 周，5–7 个小节拍，主题围绕一个地方或一个问题（例：「第一季：落脚」「第二季：小溪那边」「第三季：家里来信」）；
- 节拍条件用相处天数、等级、去过的场景、探险发现等已有数据，由 Core 判定；
- 一季讲完不会结束什么，森林和 Pibo 只会多一点东西。

### 5.2 呈现：用已经有的舞台

| 载体 | 怎么用 | 现有基础 |
| --- | --- | --- |
| Pibo 的一天（058 导演） | 3–5 拍的小演出：Pibo 走到某处、做件事、说一句。不做过场动画 | 节拍导演、地点、台词 |
| 看星星 | 夜里看星星就是在看家的方向；偶尔说一句关于故乡的话 | 058 看星星活动 |
| 出门探险与收藏架 | 少数发现物来自「远方」（舱里掉出来的零件、家乡的种子），点开有一句来历 | 收藏架、散步日记 |
| 远方来信 | 引路者的来信隔很久才到，信里是故乡的近况。信放在信箱里，Pibo 会读给你听 | 新物件（像素） |
| 地图 | 多一个「？」地点：Pibo 落地的地方，小舱在那。随季节开放 | 森林地图 |
| 时间线 | 讲过的节拍写进 056 的文字时间线，可以回看 | 时间线 |
| 森林小生物 | 松鼠、甲虫、鱼成为有名字的邻居，各自有反复出现的小事 | 058 氛围层、056 甲虫 |

### 5.3 核心关系物件（替代风铃灯）

建议用**舱里带来的那粒种子**：
- 第一季种在空地上，跟着用户的真实生活慢慢长成一棵小树，长得很慢；
- 它不提供数值；
- 它是 Pibo 想带回去的「证据」，也是一起生活的痕迹。
