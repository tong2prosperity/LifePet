# Pibo 小说工作区

本目录把 `narrative-rebuild` 中已经冻结的产品叙事转换成一部中文小说。它不替代 App 正史
决定，也不把小说专属人物和场景直接回写进产品。

## 权威顺序

1. 用户在当前任务中的明确新决定；
2. `../decisions/` 中未被替代的正式决定；
3. [`00-小说契约.md`](00-%E5%B0%8F%E8%AF%B4%E5%A5%91%E7%BA%A6.md)；
4. 后续冻结的小说人物弧、七部大纲和章节地图；
5. [`01-参考叙事技法适配.md`](01-%E5%8F%82%E8%80%83%E5%8F%99%E4%BA%8B%E6%8A%80%E6%B3%95%E9%80%82%E9%85%8D.md)；
6. 场景卡和已审核正文；
7. 写作模型的临场补充。

参考小说只影响“如何组织长篇与讲述”，Pibo 正史决定不可改变的世界与人物基础。决定 036
允许小说建立 App 主线之外的角色、阵营和冒险情节，但这些新增内容必须先在小说工作线冻结。
正文模型发现缺失信息时必须标记问题，
不能用参考小说或类型惯例补写 Pibo 世界规则。

## 计划文件

- `00-小说契约.md`：已冻结的形式、规模、视角和边界；
- `01-参考叙事技法适配.md`：参考方法在 Pibo 中的保留、转换与禁止；
- `02-小说级世界与核心危机.md`：已冻结三级连接、九十日归潮和失败后果；
- `03-阵营与主要人物群像.md`：已冻结四方阵营、十一名主要人物与三条私人关系线；
- `04-刘林克人物基础.md`：已冻结职业、性格、能力边界和叙述声音；
- `05-人物弧与知识状态.md`：已冻结十项世界秘密、三项私人历史、各部知识状态和十一人弧线；
- `06-七部故事大纲.md`：已冻结七部四十二章全书骨架；
- `07-第一部逐章与场景卡.md`：第一版已完成，第 1—2 章已进入正文；
- `scenes/`：逐场景卡；
- `continuity/`：时间线、知识状态、伏笔、物件与空间账本；
- `prompts/`：交给长上下文模型的分析、写作和审核 Prompt。
- `manuscript/`：正式正文初稿与进度索引。

受版权保护的参考小说原文不进入本仓库。只保存抽象化分析和适配结果。
