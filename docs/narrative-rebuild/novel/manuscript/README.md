## 正文流程

1. 读取小说契约、人物卡、语言卡、知识状态和当前章节场景卡；
2. 逐场景生成，不越过刘林克第一人称信息权限；
3. 完成章节后检查目标、阻力、信息变化、关系变化和章末牵引；
4. 检查对白密度、段落速度、幽默位置和人物语言辨识度；
5. 更新连续性账本，再进入下一章。
