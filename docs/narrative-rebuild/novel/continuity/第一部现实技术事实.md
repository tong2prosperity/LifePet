# 第一部现实技术事实

> 用途：保持近未来地球排查可信；正文不显示引用，不把技术核查写成教程。

## 手机应用与权限

- 移动应用的能力由签名中的 entitlement／capability 约束；没有相应能力的普通应用不能合法
  请求受保护服务。因此刘林克看到“没有安装记录、没有签名身份却能呈现窗口”时，合理地先
  怀疑系统级漏洞、管理配置或供应链攻击，而不是普通商店应用。
  [Apple Entitlements 文档](https://developer.apple.com/documentation/bundleresources/entitlements)
- iOS 会拒绝启动签名缺失或无效的应用。第一章不写刘林克在手机上直接列出所有进程；他通过
  设备存储、开发机日志、网络记录和系统行为间接判断窗口没有正常应用身份。
  [Apple Code Signing 文档](https://developer.apple.com/documentation/xcode/using-the-latest-code-signature-format)
- App Privacy Report 能显示应用访问敏感数据与联系过的网络域名，但只记录开启后的活动，
  不能证明设备绝对没有其他通信。正文让“没有域名记录”只成为证据之一，不当成最终证明。
  [Apple App Privacy Report](https://support.apple.com/en-us/102188)

## 健康数据

- 请求健康数据需要应用具备 HealthKit capability，并由系统展示细粒度授权页；用户可以按
  数据类型和历史范围决定开放内容。
  [Apple HealthKit 授权文档](https://developer.apple.com/documentation/healthkit/authorizing-access-to-health-data)

## 热成像

- 热像仪测量的是物体表面温度，准确性会受距离、环境温度和材料发射率影响。第二章只把
  热成像用于比较手机表面的相对变化，不声称它测到了森林溪水的真实温度。
  [FLIR 热像仪使用文档](https://docs.flir.com/T810603/en-US/latest/s07.html)
- 玻璃和光亮表面可能反射周围热辐射并形成误判。林见夏使用哑光胶带作参照，并明确不采用
  玻璃表面的绝对读数；故事异常是接触位置出现可重复的相对冷斑。
  [FLIR 热测量参数文档](https://docs.flir.com/T810587/en-US/latest/s11.html)

## 射电干扰与协查

- 天文射电信号远弱于常见人造发射，异常发射即使不完全覆盖观测频段，也可能污染数据；因此
  观测机构会记录时刻、频段和波形，并联系可能的设备运营方排查污染源。
  [NRAO 射频干扰说明](https://public.nrao.edu/telescopes/radio-frequency-interference/)
- 射频干扰缓解需要频率、时间、空间、参考天线和运行数据等多层信息。一次短脉冲与城市设备
  空白采样时间吻合，只足以建立协查线索，不能直接定位刘林克的手机或公寓。
  [ITU-R RA.2126-2](https://www.itu.int/dms_pub/itu-r/opb/rep/R-REP-RA.2126-2-2026-PDF-E.pdf)
- 读取权限被拒绝时，应用不能可靠区分“没有数据”和“没有读取权限”。小说第 3 章的系统层
  不宣称已经获得所有数据，也不让 Pibo 绕过系统读取。
  [Apple HealthKit 授权文档](https://developer.apple.com/documentation/healthkit/authorizing-access-to-health-data)

## 正文使用边界

- 第 1 章不出现健康权限请求；
- 不写刘林克用一条命令查看封闭手机系统的全部进程；
- 不把飞行模式等同于绝对电磁隔离；
- 不把没有网络流量当成外星结论，只用于排除普通远程控制；
- 系统截图无法捕捉窗口属于小说异常规则，不伪装成现实系统常识；
- 热像仪只能证明手机表面发生温度变化，不能直接证明画面中的水具有同一温度；
- 第 4 章的射电团队通过精确时标与公开设备状态建立相关性，不靠一次脉冲直接定位住宅；
- 未来技术与真实平台行为冲突时，优先把异常明确写成故事证据。
