# 参考叙事技法适配

> 来源：用户提供的《超魔杀帝国》抽象叙事与文风分析
>
> 性质：方法适配，不保存或复刻参考小说正文

## 核心转换

参考故事以局部异常、限知误判、问题升级和危机选择维持长篇牵引。Pibo 小说保留这套因果，
并用多人物、多阵营和跨文明的外部冒险承载它；关系、信息、使命、资源使用和告别是冲突的
内在意义，不再替代外部情节。

| 参考方法 | Pibo 中的转换 |
|---|---|
| 小问题连接更大系统 | 一次健康或森林变化逐步连接 `bo`、故乡使命和生命伦理 |
| 第一人称误判 | 刘林克依据有限信息误解 Pibo，正文保留公平线索 |
| 战斗与行动中的规则揭示 | 通过追踪、逃亡、调查、连接、记录、物件和返航限制揭示规则 |
| 危机中的保护选择 | 通过资源使用、隐瞒、等待、交出控制权和返航选择证明关系 |
| 身份谜团栈 | Pibo 身份、失忆、故乡、原使命和恢复后的隐瞒分层揭示 |
| 高压后的斗嘴 | 高压后回到克制日常、具体动作和少量程序化干幽默 |
| 世界级危机升级 | 两个文明的生存选择从“彼此有什么用”升级到“能否把生命当作资源” |
| 高潮后静场 | 返航准备之后保留一件无任务之事和安静告别 |

## Pibo 小说的牵引来源

章节不依赖连续敌人或战斗，而优先使用：

- Pibo 记住了一件按任务标准无用的事；
- 同一物件在不同阶段表现出新的关系意义；
- 一份记录与 Pibo 先前的解释不一致；
- Pibo 对某件事知道得过于准确；
- 刘林克发现 Pibo 已经先一步恢复部分信息；
- Pibo 没有选择效率最高的方案；
- 故乡的局部答案迫使双方重新理解当前约定；
- 返航条件达成以后，真正问题从“能不能走”变成“什么时候选择走”。
- 新出现的人物拥有与主角不兼容但合理的目标；
- 一次局部胜利改变力量关系，并打开更大范围的危机；
- 队伍中的秘密、旧关系和阵营责任迫使角色改变立场；
- 地球与故乡对同一证据作出完全不同、但各自合理的解释。

## 场景发动机

典型场景使用：

> 具体生活动作 → 小异常 → 刘林克形成解释 → Pibo 的行为产生偏差 → 双方行动 →
> 局部答案 → 旧理解被修正 → 留下持续变化。

场景至少改变人物位置、关系、资源、目标、风险或信息中的一项。安静场景也必须有选择和
注意力变化，但不必制造危险。

## 保留

- 限知视角；
- 公平误判；
- 多时间尺度的问题；
- 通过人物利益输送设定；
- 关系由选择证明；
- 一个答案修改旧答案；
- 高压之后的静场；
- 同一物件和环境意象随关系积累新意义。

## 语言与节奏基准

- 以中短句、短段落、高换行和高对白密度为常态；
- 常用节奏为“中短句 → 对白 → 即时判断 → 中句解释”；
- 单句成段用于笑点、突然发现、危险判断和情绪落点；
- 动作快速推进，规则发生关键变化时允许用较长句主动放慢；
- 对白同时承担人物区分、信息、关系竞争和节奏调节；
- 设定嵌入危险、利益、证据和争论，不做静态百科说明；
- 开篇保持较强幽默，随着真相与关系裂缝逐步降低；
- Pibo 继续克制，整体幽默主要由刘林克与群像承担，Pibo 的程序化认真提供反差。

## 控制

- 对白是主要叙事载体之一，但必须与行动、即时判断和空间变化共同推进；
- 幽默来自人物关系、观察、防御、自我修正、语域错位和 Pibo 的程序化反差；
- 章节结尾可以是危险、新目标、新理解或未完成动作，不必机械使用同一种悬念；
- 情绪不持续外放，重要场景反而减少解释；
- 世界观每次只揭示足以改变当前选择的部分。

## 禁止

- 复制参考小说人物、关系、专有设定、组织、能力、意象、牺牲场景或结局装置；
- 模仿独特句式、比喻、口头禅、网络梗和第四墙；
- 把 Pibo 写成高频吐槽者、傲娇角色或负责制造笑点的萌宠；
- 为保持悬念而无因果地新增敌人、秘密组织和身份翻转；
- 用战斗、死亡或不可逆伤害反复验证关系；
- 让秘密只因作者需要而不说；隐瞒必须来自已建立的人物判断和现实代价；
- 用百科对白一次性解释故乡或 `bo`；
- 用高强度文风掩盖场景缺少目标、因果或变化。

## 正文审核问题

1. 刘林克为什么在此刻必须行动？
2. 他通过什么渠道知道当前信息？
3. 他的判断是否可能出错，同时保留了公平线索？
4. Pibo 的真实优先级是否由行动而非解释显露？
5. 场景结束后什么已经变化？
6. 当前答案是否修正了旧理解，而不只是增加百科资料？
7. 幽默是否破坏了不可逆情绪瞬间？
8. 这一章是否在重复此前相同的异常和解决方式？
9. 删除所有 Pibo 专有名词后，场景是否仍有目标、阻力和关系张力？
10. 删除情绪说明后，动作是否仍能让读者理解关系？
