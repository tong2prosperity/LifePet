# 前置问题：在故事之前，我们必须相信什么

世界观、人物背景和情节都不是起点。它们是更底层判断的表达形式。
如果底层判断没有成立，失忆、约定、花或任何新设定都只会是可以互换的包装。

## 第一层：我们进入的是人的什么处境

1. 我们想陪伴的是怎样的人，在怎样一个反复发生的生活时刻？
2. 这个人表面上遇到的问题是什么，真正承受的又是什么？
3. 这是普遍的人类处境，还是团队想象出来的“用户痛点”？
4. 即使没有 App，这个处境为什么仍然值得被看见？

这一层决定产品有没有值得进入的现实。

## 第二层：我们对人持有什么判断

1. 人为什么明知健康重要，仍然会熬夜、久坐、逃避和放弃？
2. 人真正缺的是知识、意志、反馈、陪伴、被看见，还是别的东西？
3. 身体对一个人意味着什么：工具、家、边界、证据，还是重新与现实建立联系的入口？
4. 我们如何看待“没有做到”的人：需要纠正的人，还是正在用某种方式保护自己的人？

这一层决定作品的价值观，也决定 Pibo 看待用户的方式。

## 第三层：我们希望什么发生改变

1. 用户刚来时，与自己的身体是什么关系？
2. 长期相处后，这种关系希望发生什么微小但真实的变化？
3. 这个变化是更多运动、更好的指标，还是更愿意感知、照顾和重新相信自己？
4. Pibo 是变化的原因、见证者、同行者，还是用户内心某部分的外化？

这一层决定故事真正的起点和终点。健康行为只能是变化的证据，不能自动等同于变化本身。

## 第四层：为什么需要 Pibo

1. 前面的处境为什么需要一个有自主性的存在来承载，而不是图表、教练、任务系统或通知？
2. Pibo 能让什么被感知，而普通健康产品只能让它被理解？
3. 如果去掉 Pibo，这个产品失去的最重要东西是什么？
4. 如果答案只是“更可爱、更有留存”，Pibo 就还没有叙事上的存在必要。

这一层决定 Pibo 是产品的必要主体，还是附着在功能上的包装。

## 第五层：人与 Pibo 的关系为何成立

1. 用户为什么会在意 Pibo，而不只是使用它？
2. Pibo 为什么会在意这个具体的用户，而不是任何一份健康数据？
3. 双方各自需要什么，又各自能给予什么？这种交换是否对等？
4. 如果用户长期离开，Pibo 应该受伤、等待、继续生活，还是根本不以用户为中心？
5. 这段关系最珍贵的部分是什么；最危险、最容易变成情感操控的部分又是什么？

这一层决定人物关系，之后才有资格谈性格、约定、依赖和离别。

## 第六层：媒介与伦理边界

1. App 能在碎片化、重复、随时中断的使用中讲怎样的故事，不能讲怎样的故事？
2. 健康数据是剧情资源、人物感知，还是用户真实生活留下的痕迹？
3. 我们能否使用失去、衰弱和离开，而不把用户的健康焦虑变成留存工具？
4. 哪些体验即使有效，也因为会制造亏欠、羞耻或依赖而不应该做？

这一层决定叙事的边界和产品的诚实程度。

## 讨论顺序

我们不会一次回答完全部问题。先形成一句可以被反驳的“人的处境命题”，再逐层检验：

> 我们看见一些人正在 ______；我们相信这并不只是因为 ______，而是因为 ______；我们希望他们能够重新 ______。

确定这个命题后，才继续验证：

> 这件事为什么需要 Pibo 才能发生？

它们都不是宣传语或最终文案，只是所有后续设定必须共同服务、并且经得起质疑的内部假设。
