# Pibo 待验证的体验问题

> 2026-09-05 精简。产品身份已明确，见 [PRODUCT](../PRODUCT.md)；当前代码与交付状态统一见 [05](../product-strategy-202608/05-P0-Implementation-Status.md)。本文不再维护第二份工程快照。

## 优先验证

1. 健康数据到达时，用户是否看得见 Pibo 被喂养、状态发生变化？反馈不能只落在 bo 数字和物件资格上。
2. 双击、食物观察和状态动作是否有清楚的注意、意图与回应？表情和肢体应可读，既有个性也有变化。
3. 第一枚真实 bo 投入吊床后，用户是否看懂自己养出了什么永久能力？能否在之后再次看到它自主使用？
4. 除物件外，长期习惯、偏好与共同记忆怎样形成？这些属于后续设计，不宣称当前已全部实现。
5. 用户是否因想见 Pibo 而回来？是否能理解健康数据带来的成长？付费意愿应通过具体内容和真实用户验证，不由世界观完整性推断。

## 验证顺序

先验证一次真实数据反馈、一次有趣互动、一次永久成长，再扩展长期关系和商业内容。用实际使用观察区分“看懂”“喜欢”“愿意回来”和“愿意付费”，不把模拟用户当真实验证。

负面状态、长期成长和付费方案的具体规则仍按 PRODUCT 的未决边界逐项设计。工程问题直接追踪 05 及对应服务/测试，不从已删除的旧拔取或门控规格反推实现。
