## 读法

```
#### 编号 `unit.id`
槽位 · 状态 · 层级 · 记忆
Pibo：第一句 / 第二句 / 带选项的最后一句
- 「选项」→ 反应  ｜心情  ↻ 回响
```

- `/` 分句：每次双击推进一句（主动触发时第一句自动出现，之后同拍一拍节奏）；最后一句出现两个选项和「我想说…」。
- **槽位**：什么真实事件之后可以出现，定义见系统文档 §2。
- **层级**：L1 只聊 Pibo 自己和互动机制；L2 问用户今天；L3 问用户偏好。
- **记忆**：`当日`到今天结束；`偏好`保留 180 天；`—` 只做即时反应，但回响仍在当天可用。
- 自定义回复默认使用文末共享池；个别条目给出专用写法。
