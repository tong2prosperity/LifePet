## 主要修正

- 用年轻取火者、临时合作、记录与程序习惯替代“怕黑、借光求生、决定留下”的旧故事；
- Pibo 改用“我”自称，删除宠物化、幼儿化、甜腻、傲娇与泛化哲学句；
- 低睡眠、低活动、缺失数据不再让 Pibo 困、弱、花蔫或不舒服；
- 区分 Pibo 台词、系统提示和数据摘要；不再强制每条角色台词插入健康数字；
- 睡眠中的 Pibo 不开口，使用系统“请勿打扰”提示；
- `dive/coolhide` 不再被写成随机 Idle 或用户心理压力；
- 拍一拍从“70% 乱码 + 30% 哲学句”改为 Core 说话预算、动作优先和短句候选；
- 第一枚 `bo` 保持真实数据自然形成、成熟不过期、无好坏等级和无催促；
- 已经落地的 `animation.*` 成果与拍击 content key 成为对应场景的优先文案。

## 兼容处理

- 尽量保留 `ONB-*`、`DS-*`、`WK-*`、`AC-*`、`IR-*`、`ID-*`、`DI-*`、`TAP-*`、`GAR-*`、`SLP-*`、`AWK-*`、`UNK-*` 编号，供迁移检索；
- 不再适用的编号在文档中明确标为“停用”，不得进入新候选池；
- 新实现仍应逐步迁移到 Core 返回的稳定内容键，平台只负责本地化。

## 没有在本次拍板的事项

本次没有改变 Pibo 何时知道返航、何时向用户说明返航。首页规则只要求：随机日常文案不能提前说出当前故事阶段尚未公开的信息。相关事件节奏仍需在事件 03–10 的后续讨论中单独确认。
