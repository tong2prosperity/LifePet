# 双端非像素捉迷藏表现删除记录

依据用户 2026-10-25 的明确指令，iOS 与鸿蒙删除整个旧表现执行链，替换上一轮临时屏蔽开关。当前像素日程的捉迷藏、找到与超时返回保留。

删除范围：旧 mood 动画调度与 body hide 标记、草丛找回及超时回调、旧存储时间与标记、专用找到／超时文案及筛选、答案旧动画选项、调试入口和桌面组件旧状态覆盖。iOS 额外删除旧矢量角色的 `coolhide`、`grassHide`、变形采样、布局、命中与 VoiceOver 入口及专用摆动执行器。鸿蒙移除旧 mood 的应用 Native 桥接和 ArkTS 类型。

保留已发布 Core `0.34.4` 与原数字枚举／内容 ID 兼容合同，不修改领域规则或 SDK。提问、回答记忆、时间线、健康事实、bo 与物件资产不删除；旧存储的退役字段解码后忽略，后续保存不再写出。

- iOS：514 tests / 102 suites 全部通过，Debug 测试构建及 Release iOS Simulator 构建通过。
- 鸿蒙：125 项本地检查、default 产品手机／手表 HAP 构建通过。像素原始视觉基线与金值未重录。
- 新增旧回答存储与旧组件快照兼容回归；保留返家收取、真实像素藏起／找到后可见、说话前后持续绘制等覆盖。
- 两端 `git diff --check` 通过。
- 本轮未真机复验；鸿蒙既有工具链未使用参数告警仍存在。
