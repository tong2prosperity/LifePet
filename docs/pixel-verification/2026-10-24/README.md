# iOS 屏幕边缘与说明文字修复（2026-10-24）

本轮只修改 iOS。保留现有像素插画、配色和标题，修复森林白边及说明文字过小的问题。

## 屏幕边缘

森林逻辑画布原先向下取整，整数放大后可能比视口少 1–2pt，露出浅色底。现在向上取整，保持整数倍最近邻采样，居中裁切少量超出部分；备用底色取当前天空色。绘制坐标和点击坐标继续使用同一个居中偏移。

- [修复前](home-before.png) / [修复后](home-after.png)：iPhone 17 模拟器，402×874pt，夜景。
- 原图 1206×2622px 最底一行的浅色底 `(242,245,240)`：修复前 1206 像素，修复后 0 像素。
- `PixelStageCoverageTests` 覆盖 430×932、402×874、393×852、375×812、320×568 和小数视口 430.5×932.5pt。修复前出现 6 个断言失败；修复后全部通过，额外覆盖量小于一个逻辑像素。

## 说明文字

成长面板的解释、经验来源、升级提示等从 12–13pt 改为设计系统 16pt 正文，使用系统字体和 1.5 倍行高；像素标题、进度条和插画保留。来源数值改用深色、等宽数字，行高从 24pt 增至至少 36pt。

同步调整心愿、装饰、地图、纪念架及成长卡片中的同类小字。长说明允许换行，不再被两行截断。说明面板启用系统字号缩放，标题固定在上方，关闭按钮点击区 44pt，内容超过视口时滚动。大字体下成长概览纵向排列、装饰卡片减少列数。该设置限于本轮说明面板，未全局修改字体策略。

- 成长：[修复前](growth-before.png) / [修复后](growth-after.png)。实际运行中的模拟器，无健康授权。
- 同类面板：[心愿](wishes-after.png)、[装饰](decor-after.png)、[地图](map-after.png)。
- 隔离的 Lv.4 展示夹具：[430pt](growth-430-after.png)、[375pt](growth-375-after.png)、[375pt 辅助功能字号 2](growth-large-text-after.png)。

后三张由真实 `UIWindow` / `UIHostingController` 渲染，不是整机截图；使用临时 UserDefaults，未写入真实健康事实或用户账本。大字体截图仅显示初始滚动位置，测试确认内容高度超过可见区域且存在可滚动容器。截图已逐张查看，普通窄屏没有横向溢出。
