# 像素首页缺陷回归

用户报告：像素框／文字重影，Pibo 反复显隐，以及音频会话的主线程阻塞警告。

- 重影：SwiftUI 对整个容器应用零模糊阴影，文字和内部按钮也生成偏移副本。
  对话框、相机／设置按钮、足迹入口改成单独的背景矩形阴影；内部内容不投影。
- 显隐：`!pixelActorPresent` 混进陪伴控制器的 `overlayOpen`，角色隐藏后又被
  Core 的遮挡层 blocker 取消隐藏，下一轮再次隐藏。新增独立 `actorPresent` 输入，
  只阻止角色不可见时的说话／提问；情境状态仍只接收真实界面遮挡。
  像素帧也禁用外围气泡／弹层事务的隐式动画，避免对已逐帧绘制的图片再次插值。
- 音频：将会话配置／激活、AVAudioPlayer 解码、`prepareToPlay`、播放和停止统一放到
  后台串行队列。预备播放器也可能隐式激活会话，不能只把显式 `setActive` 搬走。
  激活失败不继续解码／播放；关闭音效后不执行后续播放请求。

验证：

- iPhone 17／iOS 26.5 Simulator 全量 swift-testing：465 项、91 个 suite 通过。
- iOS Debug 与 Release 模拟器构建均通过（包含内嵌 Watch 和 Widget）。
- 新回归覆盖真实舞台可见性回报下的 20 次隐藏状态更新、气泡开始／结束时的 80 帧
  角色可见性，以及音频后台线程、执行顺序、关闭与激活失败。
- 约 21.8 秒模拟器录屏：逐帧检查 438 帧角色区域，身体像素持续存在，无消失帧。
- 修复后的运行日志未出现 `AVAudioSession` 主线程 UI unresponsiveness 警告。
- [双选项气泡与首页入口截图](iphone-dialogue.png)；通过 `-PiboSpeechPreview`
  展示相同布局的临时问题，不写回答、健康事实或成长奖励。

本次设备证据来自模拟器；未将其描述为真机音频／触觉验证。
