# Pibo 游戏产品审计（完成）

范围：当前游戏场的全部游戏入口（含华容道）。判断标准不是“能运行”，而是玩家行为是否影响结果、规则是否可学习、失败是否公平、难度是否成长、反馈是否解释行为，以及入口之间是否存在换皮重复。

## 已落地决策

| 游戏 | 决策 | 证据 |
| --- | --- | --- |
| 猜拳 | 删除 | Pibo 每轮独立随机，玩家没有信息、策略或技巧；30 秒循环只是重复抽签。 |
| 捉迷藏 | 删除 | 行/列线索固定把答案缩到三个，首次判断仍为 1/3 随机；“偷看”直接跳过推理。 |
| 喂食接物 | 删除 | 与接露珠共用同一下落、拖动、碰撞模型，仅素材和计分不同，属于重复换皮。 |
| 接露珠 | 删除 | 与镜前接花瓣同为横向移动接盘、接住下落物、漏接断连击；后者另有姿态输入、黑洞规避和架机挑战，接露珠只剩稀有物与计分差异。 |
| 花开花合 | 删除 | 开始后等待 60 秒即可得到按时间计算的分数和奖励，没有输入、失败或掌握空间；主动呼吸入口已有 Pibo 漂浮与吹散迷雾。 |
| Speed Match → 闪回对照 | 重写 | 从固定三秒的单字符二选一，改为符号+颜色完整匹配；答对 5/12 次后节奏升级，加入单维近似干扰项，并按反应速度和连击计分。 |
| Train of Thought → 思绪列车 | 重写 | 去除舞台站台和底栏重复的六个同义控制，只保留舞台直接切道岔；增加连送、加速奖励、最佳连送与进错原因反馈。 |
| 吹散迷雾 | 删除 | Computer Use 的触摸降级只需重复“吹一口”，每次固定增加 8%，没有失败、取舍或掌握空间；它更接近放松工具，并与 Pibo 漂浮争夺呼吸入口。 |
| 双线闪回 | 删除 | 自动节奏与漏答反馈虽完整，但首次规则负担最高，且与记忆矩阵、闪回对照重复占据工作记忆类体验。 |
| 浇水计时 | 删除 | “等待—单点—早晚反馈”与叠花盆的时机判断重复，但没有塔高、容错缩窄或空间累积，层次明显更浅。 |
| 放置花田 | 删除 | 页面只有离线等待、收取和扩容，没有局内输入、失败、技巧或决策反馈；这是元进度系统，不应冒充小游戏。 |
| 思绪列车（二次调整） | 重写 | Computer Use 实测开始约 9 秒已自动累计 3/5 次失败；首车等待改为 1.2 秒、初速降低、生成间隔从 2.3 秒随送达数平滑加速。 |
| 宠物跑酷 | 重写 | 单键跳跃闭环成立，但 90 秒短局重复度过高；收紧为 60 秒并同步倒计时与结算文案。 |
