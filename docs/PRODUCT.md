# Pibo 产品定义

> 2026-09-05 用户确认。产品、设计、动画与文案的统一总入口。

Pibo 是一款以真实健康数据喂养的电子宠物 App。用户的睡眠与活动影响它的状态和成长；它与用户共同生活，逐渐形成习惯、记忆和关系，并用自己的方式关心用户。

## 核心体验

真实生活产生健康数据 → Pibo 接收到可见的变化 → 用户与它互动 → 留下能力成长与共同经历 → 用户期待再次见到它。

- **喂养可见**：健康带来的变化直接落在 Pibo 的精神、姿态和行为上，不能只变成库存或故事资格。`bo` 表达持续积累，并投入共同物件，带来永久能力。
- **映射直观**：睡好后舒展、更有精神；疲惫时收拢、休息。用户能理解因果即可，不要求逐条、同时复制人类的状态。它也可以根据用户状态作出自己的回应。
- **成长有两条线**：它逐渐会做更多事情；它和用户逐渐熟悉、记住细节，形成共同经历。长期习惯与记忆是设计方向，不宣称尚未实现的能力已上线。
- **陪伴有回应**：互动要让人看得见它注意到自己。关心可以通过行动或简短话语表达，也可以发出可拒绝的邀请，不把相处变成任务检查。
- **新奇来自生活痕迹**：异世界生命受到真实生活影响，是角色与健康结合的特色。具体发现、习惯与长期变化仍需设计和验证。

## 角色表达

认真、好奇、直接、有自尊，也可以开心、惊讶、困倦、失落和主动亲近。人格有连续性，表情和肢体可以丰富、鲜活、明显；简短说话不等于动作幅度小或情绪贫乏。

动作先让人看懂它在做什么，再加入个性。观察食物要读得出发现、感兴趣、端详和反应；不要求用户寻找几像素的差异。不用固定低温度/低外放评分压制表现，也不用否认关心的套话解释感情。

异世界来客、失忆的年轻取火者是故事身份，服务于养宠体验。故事窗口、故乡和返航素材继续保留，但不能否定喂养、照料、成长和陪伴，不能要求先理解世界观才能使用 App。本次没有取消或重写返航终局。

## 当前实现与边界

- Core 六状态仍为 `dataUnknown / sleeping / waking / stable / energetic / tired`；互动影响表现，不伪造健康恢复。共享阈值、规则、状态选择与冷却继续由 Core 负责。
- `bo` 来自现行真实健康来源，不由拍照、拍击、打开 App、付费或合成数据生成。成熟后保持在头顶，由用户在共同物件 Half Sheet 确认直接投入；不恢复独立拔取与背包流程。
- 健康数据有限且可能缺失。未授权、缺设备、同步中断不是低健康，也不是用户失败；允许恢复和读取真实历史，不伪造经历、对话或医学事实。
- Pibo 可以有负面状态；具体健康影响的触发、程度与恢复仍需单独设计。本次定义没有批准死亡、不可逆损失、负罪通知、权限惩罚或“少运动直接伤害 Pibo”的规则。有效历史、记忆和资产不能因基础设施错误清除。
- 相机仅在后端确认 `is_food` 后产生贴纸投影、观察和有效餐食记录；失败和非食物不伪造成功。餐食不改变主状态或 `bo`。
- 基础餐食相机、散步涂鸦和 Shadow 基础好友关系不受物件门控。好友只分享获同意的公开语义状态，不暴露原始健康指标或暗示在线。
- Apple Watch 承担同一只 Pibo 的腕上陪伴：查看最近可信状态与真实 `bo` 生长、双击得到动作和触觉回应、查看已获得能力与好友映照。2026-09-05 用户确认下线呼吸训练；本轮不做呼吸替代模式。跨日只使今日活动数字过期，不清空宠物身份、已有成长或有效关系；暂停分享与解除关系明确区分。手表互动不伪造健康恢复、不生成 `bo`。
- 商业目标是可持续盈利，优先验证丰富共同生活、空间和外观表达以及有持续成本的服务；具体价格和新增付费范围尚未确定。现行[商业边界](narrative-rebuild/decisions/028-养成社交战斗与商业化边界.md)继续生效：不购买或加速 `bo`、故事、关系、记忆或返航，保留基础社交与购买资产的持续价值。
