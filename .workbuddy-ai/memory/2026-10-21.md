## 本机构建注意（重要）

命令行沙箱会拦住 Xcode 的嵌套沙箱，`xcodebuild` 直接跑会报
`sandbox-exec: sandbox_apply: Operation not permitted`。需要：

```bash
defaults write com.apple.dt.Xcode IDEPackageSupportDisableManifestSandbox -bool YES
xcodebuild ... OTHER_SWIFT_FLAGS='$(inherited) -disable-sandbox'
```

`#Preview` 宏同理，靠 `-disable-sandbox` 才能展开。模拟器残留定位弹窗时 shutdown + boot 清掉。
