# Pibo 主页 · 功能说明 & 文案池

> 供开发、设计对接。当前阶段：魔丸态（Day 1–14），Pibo 刚到地球，听不懂人话，只在乎头上的花。  
> **原则**：所有状态判断直接基于 HealthKit 原始数据，不经过心情/精力/体力二次映射。文案用乱码 + 音节片段，混入存在主义碎片。

---

## 一、总体区域说明

主页分为三个交互区域：

| 区域 | 内容 | 交互方式 |
|---|---|---|
| **首页打招呼文案区** | 时间问候 + 相识天数 + Pibo 日记 | 纯展示，无交互 |
| **Pibo 活动区** | Pibo 形象、拍一拍、拔毛 | 点击拍一拍、定时拔毛 |
| **上滑 Dashboard** | 向上滑动进入历史数据二楼 | 上滑手势，查看当日/历史健康数据 |
| **拍照交互** | 相机入口、拍照流程、预览弹幕 | 点击露珠相机、拍摄、保存 |

> **上滑 Dashboard**：原能量球组件已移除。用户从主页底部向上滑动，进入历史数据二楼，展示当日健康数据可视化（风吹草地、睡眠云朵、露珠活动、运动卡片、体征面板、饮食画廊）。上滑手势自然、不占用主页视觉空间。

## 三、Pibo 活动区

### 3.1 日常动画判断逻辑（6 种状态）

Pibo 的活动区表现由 **时间节律 + HealthKit 数据 + 交互频次** 共同决定，每天在这 6 种状态间切换：

| # | 状态 | 触发条件 | Pibo 在干什么 | 花的形态 |
|---|---|---|---|---|
| 1 | **深眠** | 22:00–06:00；或拔毛后 5 分钟内 | 自己的睡眠周期，花也休息 | 花低垂，颜色暗 |
| 2 | **初醒** | 06:00–10:00 用户首次打开 App | 刚醒，懵，慢慢感知地球 | 花微微抬头 |
| 3 | **发呆** | 数据普通，无特殊事件 | 观察地球，最常见状态 | 花平静，偶尔随风动 |
| 4 | **活跃** | 步数 ≥10000 或 有主动运动 | 感受到能量，舒服 | 花颜色鲜艳，微微发光 |
| 5 | **烦躁** | 步数 <3000 且无运动；或 睡眠 <5h | 花蔫了，自己不舒服 | 花垂头，颜色灰 |
| 6 | **被打扰** | 10 分钟内拍 ≥3 次 | 被连续干扰，不耐烦 | 花抖动 |

**状态优先级**：被打扰 > 深眠 > 初醒 > 活跃/烦躁 > 发呆  
（活跃和烦躁互斥，由数据判断）

**一天中的状态流动示例**：

```
07:00 用户打开 App → 初醒（懵）
09:00 步数 2000，无运动 → 发呆（观察）
12:00 步数 6000，无运动 → 发呆（继续观察）
18:00 步数 11000，有跑步 → 活跃（舒服）
22:00 拔毛时间 → 深眠（花结籽，Pibo 睡觉）
```

### 3.2 拍一拍反应概率

魔丸态 Pibo **大部分时候不鸟你**。点击 Pibo 身体区域时：

| 概率 | 反应 | 表现 |
|---|---|---|
| **60%** | 不理睬 | Pibo 背对用户 / 屁股对着你 / 侧身，无任何文字 |
| **25%** | 轻微感知 | 身体轻微抖动一下，无文字，眼睛可能眨一下 |
| **10%** | 说一句话 | 弹出当前状态对应的表层文案 |
| **5%** | 深层碎片 | 闪现存在主义剧情感碎片（见 3.3） |

**连拍覆盖规则**：10 分钟内拍 ≥3 次，从第 3 次起 **100% 进入被打扰状态**，强制说话。

### 3.3 各状态文案池

每个状态分**表层**（90%，对当下的感知）和**深层**（10%，存在主义碎片）。

> 文案风格：乱码 + 音节片段 + 省略号。偶尔出现可识别的词：花、光、暗、热、跳、甜、苦、风、云、颜色、形状。  
> 深层碎片像信号不好的收音机偶尔收到的频道——**断裂的词，不是完整句子**。

#### 深眠（22:00–06:00 / 拔毛后）

表层：
- `…zzz…`
- `…暗…`
- `…花…睡…`
- `…静…`
- `…嗯…`

深层：
- `…被…告诉…只…种…`
- `…为什么…在这里…`
- `…使命…完成…不了…`
- `…之外…没有…？`

#### 初醒（06:00–10:00 首次打开）

表层：
- `…亮…？`
- `…嗯…`
- `…花…？`
- `…时间…？`
- `…又…亮…`

深层：
- `…又是…一天…`
- `…为什么…醒…`
- `…种…之外…？`

#### 发呆（日常 / 空闲自言自语）

表层（观察地球）：
- `…云…`
- `…风…`
- `…颜色…`
- `…形状…`
- `…声音…`
- `…嗯…`
- `…？`

深层：
- `…地球…没有…答案…`
- `…观察…就是…意义…？`
- `…种花…之外…？`
- `…被…教育…只…种…`
- `…感觉…不到…目的…`

**自言自语机制**：Pibo 空闲 15–30 秒后，有 20% 概率自己飘一句（不点击也会说）。优先使用发呆态文案池。

#### 活跃（步数 ≥10000 或有主动运动）

- `…热…`
- `…跳…`
- `…亮…`
- `…快…`
- `…花…高兴…`

- `…想要…什么…？`

#### 烦躁（步数 <3000 且无运动；或 睡眠 <5h）

- `…暗…`
- `…蔫…`
- `…不舒服…`
- `…别…`
- `…#@!%…`

- `…种不好…存在…？`

- `…别…`
- `…吵…`
- `…#@!%…`
- `…走…`
- `…烦…`

深层：

### 3.4 能量收集（系统提示 + Pibo 气泡）

**触发源**：HK 后台推送检测到事件

| 事件类型 | 检测方式 |
|---|---|
| 主动运动结束 | `HKWorkout` 新增记录 |
| 睡眠数据更新 | `sleepAnalysis` 昨日数据补齐 |
| 拍照保存 | 用户调用相机并点击保存 |

**交互流程**：

```
App 前台/后台 → 检测到新事件 → 播放头顶毛动画（3s）→ 弹出能量卡片
                        ↓
                若 App 在后台 → 保存待展示标记 → 下次进前台时补播
```

**头顶毛动画（设计交付）**：
- 阶段1（0–0.8s）：毛抖动 — 头顶叶片/绒毛轻微颤抖
- 阶段2（0.8–2s）：发力 — 毛竖起，微微发光
- 阶段3（2–3s）：长出叶片 — 新叶片从头顶冒出，弹出小星星粒子
- 播完：缩回主页，头顶保留新状态

**能量卡片弹出**：动画结束后从底部滑出「今日数据」卡片，自动定位到对应数据区块。

| 事件类型 | 卡片定位 | 系统提示文案（人类视角） |
|---|---|---|
| 运动 | 运动区块 | 收集到运动能量！ |
| 睡眠 | 睡眠区块 | 睡眠能量已更新 |
| 拍照 | 今日记录区块 | 记录已保存 |

**Pibo 气泡文案（乱码视角）**：

| 事件 | Pibo 感知 | 文案 |
|---|---|---|
| 运动完成 | 感觉到"热"、"跳"、"快" | `…热…` `…跳…` `…亮…` `…快…` `…#@!%…亮…` |
| 睡眠更新 | 感觉到"暗"、"静"、"甜" | `…暗…` `…甜…` `…静…` `…花…休息…` |
| 拍照记录 | 看到"颜色"、"形状" | `…颜色…` `…记…` `…形状…` `…？` |

### 3.5 拔毛（收取花籽）

**触发**：每天晚上 22:00，用户首次打开 App 时触发。  
**机制**：收集当日健康数据 → 评定等级 → 播放拔毛动画 → 获得「今日之毛/花籽」

> 如果 22:00 后未打开 App，次日首次打开时补触发。如果当天已收取过，不再重复。  
> **如果用户当晚未打开 App**：Pibo 自己把花籽带走，次日用户收取页面显示空白/没有。

**等级映射**：

| 等级 | 条件 | 花籽视觉 | Pibo 文案 |
|---|---|---|---|
| **好** | 睡眠 ≥7h 且 有运动 | 饱满、鲜亮、翠绿 | `…给…你…` `…花…送的…` `…拿着…` |
| **中** | 睡眠 5–7h 或 仅有其中一项达标 | 普通、黄绿 | `…掉…` `…小…` `…嗯…` |
| **坏** | 睡眠 <5h 且 无运动 | 干瘪、灰褐 | `…干…` `…皱…` `…花…不好…` `…#@!%…` |

**拔毛动画（设计交付）**：
- Pibo 头顶的花轻轻颤动，一颗花籽从花上脱落
- 花籽飘向画面中央，Pibo 用手/叶推了一下
- 弹出文字：「Pibo 把今天的毛送给你了」
- 花籽落入收藏区

**拔毛后**：Pibo 进入 5 分钟深眠状态（闭眼，花低垂，不响应拍一拍）。

**次日未收取的空白状态**：
- 收取页面显示虚线轮廓占位
- 文案：`…昨天…带走了…` 或 `…没…等到…` 或 `…Pibo…自己…收…`

### 3.6 背景更换逻辑

Pibo 活动区的背景随时间和数据变化：

| 条件 | 背景变化 |
|---|---|
| 深眠状态（22:00–06:00） | 天空变暗，出现星星/月亮，地面变暗 |
| 初醒状态（06:00–10:00） | 天空泛白，太阳刚升起，晨雾 |
| 活跃状态 | 天空更亮，云朵飘动加快，地面花朵更鲜艳 |
| 烦躁状态 | 天空偏灰，云朵不动，地面花朵蔫 |
| 下雨（根据天气 API） | 天空灰，雨滴，地面湿润反光 |

## 四、拍照交互

**触发**：点击地面露珠相机  
**流程**：打开相机 → 拍摄 → 扫描线 → 预览页 → Pibo 弹幕 → 保存/重拍

### 4.1 拍照时 Pibo 弹幕

**位置**：照片预览页，`pibo-comment` 区域  
**识别**：暂时不做 AI 识别，按拍照时间硬卡文案

| 拍照时间 | 文案（随机抽一条） |
|---|---|
| 6:00–10:00 | `…颜色…？` `…地球…早上…吃…？` `…圆…？` `…形状…怪…` |
| 11:00–14:00 | `…亮…` `…这个…？` `…能吃…？` `…颜色…记…` |
| 17:00–20:00 | `…暗了…还吃…？` `…一天…几次…？` `…饱…？` |
| 其他时间 | `…又吃了…？` `…Pibo记住了…` `…好奇特的味道…` |

**通用弹幕（任意时间随机出现）**：

- `…这个…能吃？`
- `…地球的…食物…好奇怪…`
- `…#@!%…闻起来…`
- `…花…不吃…这个…`
- `…人的能量…从这儿来…？`
- `…Pibo…只能…光合作用…`
- `…看起来…比土壤…好吃…`
- `…颜色…没…见过…`
- `…形状…不像…花…`
- `…地球…东西…都…能吃？`

### 4.2 保存后的 Pibo 反应

照片保存后，Pibo 活动区可能触发：
- 头顶花轻微晃动（感知到新认知能量）
- 50% 概率飘一句拍照相关文案（使用拍照弹幕池）
