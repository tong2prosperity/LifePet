# Pibo 主页 · 功能说明 & 文案池

> 供开发对接。当前阶段：魔丸态，Pibo 刚到地球，听不懂人话，只在乎头上的花。  
> **原则**：所有状态判断直接基于 HealthKit 原始数据，不经过心情/精力/体力二次映射。文案用乱码 + 音节片段，混入存在主义碎片。
> 人为修改中，目前只确定了二首页打招呼的文案，其他的还在审核修改

---

## 一、总体区域说明

主页分为三个交互区域：

| 区域 | 内容 | 交互方式 |
|---|---|---|
| **首页打招呼文案区** | 时间问候 + 相识天数 + Pibo 日记 | 纯展示，无交互 |
| **Pibo 活动区** | Pibo 形象、拍一拍、拔毛 | 点击拍一拍、定时拔毛 |
| **上滑 Dashboard** | 向上滑动进入历史数据二楼 | 上滑手势，查看当日/历史健康数据 |
| **拍照交互** | 相机入口、拍照流程、预览弹幕 | 点击露珠相机、拍摄、保存 |

> **上滑 Dashboard**：原能量球组件已移除。用户从主页底部向上滑动，进入历史数据二楼，展示当日健康数据可视化（风吹草地、睡眠云朵、露珠活动、运动卡片、体征面板、饮食画廊）。上滑手势自然、不占用主页视觉空间。

## 三、Pibo 活动区

### 3.1 日常动画判断逻辑（6 种状态）

Pibo 的活动区表现由 **时间节律 + HealthKit 数据** 共同决定，每天在这几种状态间切换：

| # | 状态 | 触发条件 | Pibo 在干什么 | 花的形态 |
|---|---|---|---|---|
| 1 | **深眠** | 22:00–06:00；或拔毛后 5 分钟内 | 自己的睡眠周期，花也休息 | 花低垂，颜色暗 |
| 2 | **初醒** | 06:00–10:00 用户首次打开 App | 刚醒，懵，慢慢感知地球 | 花微微抬头 |
| 2a | **初醒·睡够** 🅿️ | 初醒态 + 昨日睡眠 ≥7h | 精神尚可，花抬得较高 | 花抬头，颜色鲜亮 |
| 2b | **初醒·没睡够** 🅿️ | 初醒态 + 昨日睡眠 <7h | 更懵，花抬得低 | 花微微抬头，颜色略暗 |
| 3 | **发呆** | 数据普通，无特殊事件 | 观察地球，最常见状态 | 花平静，偶尔随风动 |
| 4 | **活跃** | 步数 ≥10000 或 有主动运动 | 感受到能量，舒服 | 花颜色鲜艳，微微发光 |
| 5 | **烦躁** | 步数 <3000 且无运动；或 睡眠 <5h | 花蔫了，自己不舒服 | 花垂头，颜色灰 |
| 6 | **被打扰** 🅿️ | 10 分钟内拍 ≥3 次 | 被连续干扰，不耐烦 | 花抖动 |

> 🅿️ = 选做。设计资源不足时，初醒不分睡够/没睡够，被打扰态暂不做。

**状态优先级**：深眠 > 初醒（·睡够 / ·没睡够）> 活跃/烦躁 > 发呆  
（活跃和烦躁互斥，由数据判断。被打扰为选做态，若做则优先级最高）

**一天中的状态流动示例**：

```
07:00 用户打开 App → 初醒（懵）
09:00 步数 2000，无运动 → 发呆（观察）
12:00 步数 6000，无运动 → 发呆（继续观察）
18:00 步数 11000，有跑步 → 活跃（舒服）
22:00 拔毛时间 → 深眠（花结籽，Pibo 睡觉）
```

### 3.2 拍一拍反应

魔丸态 Pibo 对拍一拍只有两种反应：**不理睬** 或 **说一句话**。

**两种反应状态**：

| 状态 | 表现 | 说明 |
|---|---|---|
| **不理睬** | Pibo 背对用户 / 屁股对着你 / 侧身，无任何文字 | 默认状态，大部分时候不回应 |
| **说一句话** | 弹出当前状态对应的文案（见 3.3） | 受次数限制，说多了就不理了 |

**说话次数限制**（硬性上限）：

```
每 10 分钟内 → 最多说 3 句话
每 24 小时内 → 最多说 9 句话
```

**触发逻辑**：

```
if 当日已达 9 句上限:
    → 100% 不理睬
elif 10 分钟内已达 3 句上限:
    → 100% 不理睬
else:
    → 30% 概率说一句话，70% 不理睬
```

> 具体概率可调。核心设计：Pibo 是吝啬说话的，但也不是完全沉默。

### 3.3 各状态文案池

> 文案风格：省略号分隔的短句，词可读，带一点 Pibo 的俏皮和傲娇。有主语（Pibo / 花），有简单动作，偶尔带语气词（啵 / 呢 / 啊）。  
> 不是纯乱码，也不是完整人话，是中间态——像刚到地球的外星人在努力拼凑句子。

#### 深眠（22:00–06:00 / 拔毛后）

- `...zzz...`
- `...花...睡了...`
- `...暗...`
- `...静...`

#### 初醒·睡够 🅿️（06:00–10:00 首次打开 + 昨日睡眠 ≥7h）

- `...亮...？`
- `...花...醒了...`
- `...嗯...`
- `...花...精神...`

#### 初醒·没睡够 🅿️（06:00–10:00 首次打开 + 昨日睡眠 <7h）

- `...亮...？`
- `...花...还困...`
- `...不想...醒...`
- `...花...没精神...`

#### 发呆（日常 / 空闲自言自语）

- `...云...在飘...`
- `...风...`
- `...颜色...好看...`
- `...形状...怪...`
- `...嗯...`
- `...？`

**自言自语机制**：Pibo 空闲 15–30 秒后，有 20% 概率自己飘一句（不点击也会说）。优先使用发呆态文案池。

#### 活跃（步数 ≥10000 或有主动运动）

- `...热...`
- `...跳...`
- `...花...高兴...`
- `...发芽了啵！`
- `...亮...`

#### 烦躁（步数 <3000 且无运动；或 睡眠 <5h）

- `...花...没精神...`
- `...暗...`
- `...不舒服...`
- `...花...蔫了...`
- `...别...`

#### 被打扰 🅿️（10 分钟内拍 ≥3 次）

- `...别碰...`
- `...吵...`
- `...烦...`
- `...走...`

### 3.4 能量收集（系统提示 + Pibo 气泡）

**触发源**：HK 后台推送检测到事件

| 事件类型 | 检测方式 |
|---|---|
| 主动运动结束 | `HKWorkout` 新增记录 |
| 睡眠数据更新 | `sleepAnalysis` 昨日数据补齐 |
| 拍照保存 | 用户调用相机并点击保存 |

**交互流程**：

```
App 前台/后台 → 检测到新事件 → 播放头顶毛动画（3s）→ 弹出能量卡片
                        ↓
                若 App 在后台 → 保存待展示标记 → 下次进前台时补播
```

**头顶毛动画**：设计交付，由设计团队定义。核心概念：Pibo 头顶的花/毛感知到新能量后发生轻微变化（抖动 → 生长 → settled）。动画时长约 3s，结束后缩回主页。

**能量卡片弹出**：动画结束后从底部滑出「今日数据」卡片，自动定位到对应数据区块。

| 事件类型 | 卡片定位 | 系统提示文案（人类视角） |
|---|---|---|
| 运动 | 运动区块 | 收集到你的运动能量！ |
| 睡眠 | 睡眠区块 | 睡眠能量已更新 |
| 拍照 | 今日记录区块 | 记录已保存 |

**Pibo 气泡文案**：

| 事件 | 文案（随机抽一条） |
|---|---|
| 运动完成 | `Pibo...感觉到了...` / `...热...` / `...跳...` / `...发芽了啵！` |
| 睡眠更新 | `Pibo...也...睡了...` / `...花...休息...` / `...暗...甜...` |
| 拍照记录 | `花...不吃...这个...` / `...颜色...记...` / `...地球...食物...` |

### 3.5 拔毛（收取花籽）

**触发窗口**：每天晚上 22:00–02:00。用户首次打开 App 时触发花籽收取。

> **过期清空**：超过 02:00 未收取，花籽自动清空，进入新一天状态。次日打开 App 时不补发，Pibo 直接进入新一天的周期。

**等级映射**：

| 等级 | 条件 | 花籽视觉 | Pibo 文案 |
|---|---|---|---|
| **好** | 睡眠 ≥7h 且 有运动 | 饱满、鲜亮、翠绿 | `...给...你...` / `...花...送的...` / `...拿着...` |
| **中** | 睡眠 ≥6h（且不满好条件） | 普通、黄绿 | `...掉...` / `...小...` / `...嗯...` |
| **坏** | 睡眠 <6h 或 步数 <3000（达成任意一个） | 干瘪、灰褐 | `...干...` / `...皱...` / `...花...不好...` |

**拔毛动画（设计交付）**：
- Pibo 头顶的花轻轻颤动，一颗花籽从花上脱落
- 花籽飘向画面中央，Pibo 用手/叶推了一下
- 弹出文字：「Pibo 把今天的毛送给你了」
- 花籽落入收藏区

**拔毛后**：Pibo 进入 5 分钟深眠状态（闭眼，花低垂，不响应拍一拍）。

**次日未收取的空白状态**：
- 收取页面显示虚线轮廓占位
- 文案：`...昨天...带走了...` / `...没...等到...` / `...Pibo...自己...收...`

### 3.6 背景更换逻辑

Pibo 活动区的背景随时间和数据变化：

| 条件 | 背景变化 |
|---|---|
| 深眠状态（22:00–06:00） | 天空变暗，出现星星/月亮，地面变暗 |
| 初醒状态（06:00–10:00） | 天空泛白，太阳刚升起，晨雾 |
| 活跃状态 | 天空更亮，云朵飘动加快，地面花朵更鲜艳 |
| 烦躁状态 | 天空偏灰，云朵不动，地面花朵蔫 |

## 四、拍照交互

**触发**：点击地面露珠相机  
**流程**：打开相机 → 拍摄 → 扫描线 → 预览页 → Pibo 弹幕 → 保存/重拍

### 4.1 拍照时 Pibo 弹幕

**位置**：照片预览页，`pibo-comment` 区域  
**识别**：暂时不做 AI 识别，按拍照时间硬卡文案

| 拍照时间 | 文案（随机抽一条） |
|---|---|
| 6:00–10:00 | `…颜色…？` `…地球…早上…吃…？` `…圆…？` `…形状…怪…` |
| 11:00–14:00 | `…亮…` `…这个…？` `…能吃…？` `…颜色…记…` |
| 17:00–20:00 | `…暗了…还吃…？` `…一天…几次…？` `…饱…？` |
| 其他时间 | `…又吃了…？` `…Pibo记住了…` `…好奇特的味道…` |

**通用弹幕（任意时间随机出现）**：

- `…这个…能吃？`
- `…地球的…食物…好奇怪…`
- `…#@!%…闻起来…`
- `…花…不吃…这个…`
- `…人的能量…从这儿来…？`
- `…Pibo…只能…光合作用…`
- `…看起来…比土壤…好吃…`
- `…颜色…没…见过…`
- `…形状…不像…花…`
- `…地球…东西…都…能吃？`

### 4.2 时间戳显示

照片预览页和已保存的照片卡片上显示拍照时间：

| 位置 | 格式 | 示例 |
|---|---|---|
| 照片预览页左下角 | `YYYY.M.D HH:mm AM/PM` | 2026.6.6 00:33 AM |
| 历史页照片卡片 | `YYYY.M.D HH:mm` | 2026.6.6 00:33 |

### 4.3 保存后的 Pibo 反应

照片保存后，Pibo 活动区可能触发：
- 头顶花轻微晃动（感知到新认知能量）
- 50% 概率飘一句拍照相关文案（使用拍照弹幕池）
